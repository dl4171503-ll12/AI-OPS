# AI一人学校 · 项目总览与路线图

## 项目背景
面向6-18岁学生的AI个性化学习平台，以游戏化的"学校"形态呈现，让孩子一进来就觉得像在玩游戏，而不是冷冰冰的学习网页。

每一栋教学楼 = 一个AI学科老师，校长总管全局，心理老师关注情绪成长，娱乐楼探索兴趣，校际社交让孩子拥有同伴。

## 核心角色
- **校长**：AI总指令官，部署各学科教学节奏，给出全局学习建议
- **数学老师 / 语文老师 / 英语老师 / 科学老师 / 艺术老师 / 体育老师**：各学科AI老师，独立教研
- **心理老师**：关注孩子情绪和心理健康，分年龄段沟通
- **学生（用户）**：一人一所学校，专属成长空间

## 年龄段分层
| 阶段 | 年级 | 界面风格 | 交互特点 |
|------|------|---------|---------|
| 低龄段 | 1-4年级 | 极卡通、大图标 | 图片多文字少、有配音、游戏化高 |
| 高龄段 | 5-6年级+初中 | 半卡通半写实 | 知识性增强、自主规划、平等对话 |
| 高中段 | 高中 | 简洁高效 | 深度内容、目标管理、自律导向 |

晋升时有仪式感动画，全校视觉风格同步更新。

## 技术建议
- 前端：React 或 Vue（选团队熟的）
- 后端：Node.js
- 数据库：SQLite（开发期）/ PostgreSQL（上线）
- AI模型：统一封装LLM接口，支持Claude/GPT/通义等切换
- 实时通信：WebSocket（社交功能用）

## 1.0 验收标准
- [ ] 新用户注册→创建学校→测评→学习，全流程无卡点
- [ ] 至少3个学科可用
- [ ] 校长、心理老师正常工作
- [ ] 年龄段适配生效
- [ ] 错题本+学习报告完整
- [ ] 家长端可查看所有数据
- [ ] 晋升仪式可触发
- [ ] 首屏<3秒，AI响应<10秒
