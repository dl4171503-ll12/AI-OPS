# 第四阶段：娱乐探索 + 校际社交 + 安全监管

## 目标
加入非学习类功能，让学校更完整；实现校际社交+安全防火墙。
注意：社交功能涉及儿童安全，是重中之重。

## 提示词（直接复制给 Cursor / 开发 Agent）

---

继续开发"AI一人学校"第四阶段：娱乐探索空间和校际社交功能。

**新增功能模块：**

1. **娱乐与自我探索楼**
   - 一栋独立的楼，风格活泼多彩
   - 内部包含多个兴趣房间（可扩展）：
     - 体育兴趣室：体育知识、运动科普、名将故事
     - 美术创意室：AI画画、艺术知识、名画欣赏
     - 音乐室：乐器介绍、乐理入门、AI作曲互动
     - 编程室：Scratch入门、趣味编程挑战
   - 核心逻辑：不是教学，是"探索"，让孩子发现自己的兴趣
   - 每个兴趣室记录孩子的探索时长和偏好，形成"兴趣画像"

2. **开放式探索空间**
   - 一个类似广场/花园的开放区域
   - 孩子可以在这里"随便逛"，随机发现小彩蛋、小知识
   - 支持AI对话：孩子问任何问题都可以（十万个为什么模式）
   - AI根据孩子的兴趣画像推荐相关内容

3. **校际社交系统**
   - 概念：每个孩子的"学校"是独立的，但可以和其他学校互动
   - 功能：
     - 好友系统：通过学校ID/邀请码加好友
     - 公共广场：所有小朋友的学校都可以"串门"
     - 可以一起做练习题PK、交换学习心得、分享成就徽章
     - 好友学校之间可以互赠小礼物（虚拟徽章、贴纸）
   - 社交场景要温和、积极，围绕学习和兴趣展开，不做纯闲聊社交

4. **社交安全监管（重中之重）**
   - 所有聊天内容经过AI实时审核
   - 审核规则：
     - 禁止泄露个人信息（姓名、学校、住址、手机号、微信等）
     - 禁止辱骂、欺凌、不当言论
     - 禁止讨论不适合年龄段的内容
     - 小龄段（1-4年级）：家长端可以看到全部聊天内容
     - 高龄段：家长端只能看到风险摘要，保护隐私
   - 风险分级：
     - 轻度提醒：AI以系统消息形式温和提醒
     - 中度警告：消息拦截+通知家长
     - 重度：禁言+强制通知家长
   - 家长端有完整的社交安全控制面板

**技术要求：**
- 社交功能需要后端服务支持（WebSocket实时通信）
- 内容审核模块独立设计，可替换不同的审核API
- 所有聊天记录加密存储
- 兴趣画像数据结构清晰，用于后续推荐

**交付物：**
- 娱乐探索楼+4个兴趣室（基础版）
- 开放式探索空间
- 好友系统+公共广场
- AI内容审核+安全分级机制
- 家长端社交安全控制面板
