# 第二阶段：学科AI老师（以数学楼为例）

## 目标
以数学楼为例，实现完整的AI老师闭环——测评→个性化方案→练习→反馈→错题本。
跑通一栋楼，其余学科复用同一套架构。

## 提示词（直接复制给 Cursor / 开发 Agent）

---

继续开发"AI一人学校"第二阶段：数学楼AI老师完整功能。

**核心逻辑：** 每一栋教学楼就是一个AI学科老师，具备4个核心能力：了解学情、知识库支撑、个性化方案、反馈提升。

**具体功能：**

1. **进入数学楼的二级界面**
   - 场景：教室风格，有黑板、讲台、课桌
   - AI数学老师形象出现在讲台旁（用卡通头像+对话气泡）
   - 左侧功能菜单：学情档案、今日任务、练习题、错题本、学习报告

2. **学情测评系统**
   - 首次进入时，AI老师引导学生做一套测评题（10-15道）
   - 根据答题情况分析：强项、弱项、易错点、知识掌握程度
   - 生成可视化的学情雷达图或知识图谱
   - 测评结果存入学生档案

3. **AI知识库（数学老师的"大脑"）**
   - 内置小学数学知识体系（按年级/知识点分层）
   - 支持后续扩展：导入教材、课程内容、习题集
   - AI老师调用大模型时，带上学生的学情数据+学科知识库，确保回答专业且符合年龄段

4. **个性化学习方案生成**
   - 根据学情测评结果，AI自动生成本周/本日学习计划
   - 每天的任务包括：知识点讲解、例题、练习题、小测验
   - 难度自适应：答对了升级难度，答错了降级并补充基础

5. **练习与错题本**
   - 学生做完题后即时判分+讲解
   - 错题自动收入错题本，按知识点分类
   - 错题本支持"重练"功能，AI生成同类题目

6. **学习报告**
   - 每日/每周学习报告：学习时长、掌握知识点、错题分析、进步情况
   - 家长端可以查看报告

**技术要求：**
- 接入大模型API（留好配置接口，支持Claude/GPT/通义等）
- 学生学情数据结构化存储，方便后续分析
- 数学题支持LaTeX公式渲染
- 所有AI交互有loading状态和重试机制

**交付物：**
- 数学楼完整功能（测评→方案→练习→错题→报告）
- 可复用的学科老师模板架构，后续语文/英语等直接套用
- 数据库设计：学生档案、学情数据、错题本、学习记录

- [ ] 学生可以做题，做完即时判分+讲解
- [ ] 错题自动收入错题本，支持重练
- [ ] 能生成每日/每周学习报告
- [ ] 代码结构支持其他学科快速复用
