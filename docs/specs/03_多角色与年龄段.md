# 第三阶段：多角色体系 + 年龄段分层

## 目标
加入校长、心理老师等角色，实现年龄段切换的仪式感和内容适配。
让整个学校从"只有学科老师"变成"有完整生态的学校"。

## 提示词（直接复制给 Cursor / 开发 Agent）

---

继续开发"AI一人学校"第三阶段：多角色体系和年龄段分层机制。

**新增角色：**

1. **校长（AI总指令官）**
   - 位置：学校大门口/校长办公楼
   - 功能：
     - 总体了解学生所有学科的学习情况
     - 给出全局学习建议和优先级安排
     - 协调各学科老师的教学节奏
     - 学生可以找校长"聊天"，说自己的烦恼或目标
   - 人设：温和但有智慧的长者形象，说话有哲理但不啰嗦

2. **心理老师**
   - 位置：心理咨询室（独立建筑，在学校一角，温馨风格）
   - 功能：
     - 随时可以找心理老师聊天，说学习/生活/人际交往中的烦恼
     - 了解对应年龄段孩子的心理特点，用孩子能接受的方式沟通
     - 低龄段：讲故事、拟人化引导为主
     - 高龄段：更平等的对话、认知调整
     - 情绪追踪：记录孩子的情绪变化，异常时温和提醒家长（在报告中体现）
   - 人设：温暖、有耐心、像知心大姐姐/大哥哥

**年龄段分层机制（核心功能）：**

1. **三个阶段划分**
   - 低龄段（1-4年级）：界面更卡通、交互更简单、图片多文字少、有配音、游戏化程度高
   - 高龄段（5-6年级+初中）：知识性增强、文字变多、交互更自主、开始有自主规划
   - 高中段：内容深度加大、界面更简洁高效、强调自律和目标管理

2. **阶段晋升仪式感**
   - 当学生的学习水平达到某个阶段的毕业标准时，触发"晋升仪式"
   - 画面：全校老师集合、校长颁发毕业证书、放烟花/彩带动画
   - 晋升后：整个学校的视觉风格发生变化（从卡通→更成熟），教学楼外观更新
   - 学生获得"毕业徽章"，解锁新功能

3. **内容适配逻辑**
   - 每个学科老师在生成内容时，必须带上学生的年龄段参数
   - AI提示词中强制说明："用XX年龄段孩子能理解的语言和例子讲解"
   - 界面元素（字体大小、配色、动画程度）随年龄段自动调整

**技术要求：**
- 年龄段作为全局参数，所有AI调用都带上
- 角色对话有独立的system prompt和人设
- 晋升机制有明确的触发条件和数据记录
- 心理老师的对话记录单独存储，仅家长端可见摘要

**交付物：**
- 校长角色+办公楼界面
- 心理老师+咨询室界面
- 年龄段分层机制和内容适配
- 晋升仪式动画和界面切换
- 家长端报告新增情绪/心理状态摘要

---

## 阶段验收标准
- [ ] 校长办公楼可进入，校长能给出全局学习建议
- [ ] 心理咨询室可进入，心理老师能正常对话
- [ ] 年龄段参数全局生效，不同年级界面风格有差异
- [ ] AI回答内容符合对应年龄段理解水平
- [ ] 晋升条件可触发，仪式动画完整
- [ ] 晋升后全校视觉风格同步更新
- [ ] 心理老师对话记录独立存储，家长端可见情绪摘要
