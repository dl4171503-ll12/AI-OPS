# 第一阶段：学校主界面 + 游戏化框架

## 目标
搭出整个产品的壳，让用户一进来就看到"我的学校"游戏界面。完成基础框架、路由、用户信息存储。

## 提示词（直接复制给 Cursor / 开发 Agent）

---

帮我开发一个"AI一人学校"Web应用的第一阶段：学校主界面和基础框架。

**项目背景：**
这是一个面向6-18岁学生的AI个性化学习平台，以游戏化的"学校"形态呈现，让孩子一进来就觉得像在玩游戏，而不是冷冰冰的学习网页。

**技术栈：**
用你认为最适合快速开发的前端框架（React/Vue都可以），后端用Node.js，数据库用SQLite或MongoDB，能快速跑起来就行。

**核心需求：**

1. **初始登录/创建学校界面**
   - 玩家输入名字，选择头像
   - 选择当前年级（小学低段/高段/初中/高中）
   - 有"创建我的学校"按钮，点击后有建造动画，然后进入主界面

2. **学校主界面（俯视/斜视角游戏风格）**
   - 画面中央是校园，有6栋教学楼：数学楼、语文楼、英语楼、科学楼、艺术楼、体育中心
   - 每栋楼有独立的建筑外观和图标，卡通可爱风格
   - 鼠标悬停在楼上会显示楼的名称和简介
   - 点击楼进入对应的二级界面

3. **角色导航栏**
   - 左上角：学生头像、名字、年级、学习天数、成就徽章
   - 右上角：设置、家长中心入口

4. **界面风格**
   - 整体明亮、卡通、游戏化，类似Minecraft或模拟人生的画风
   - 有背景音效开关（可选）
   - 响应式，支持电脑和平板

**交付物：**
- 完整可运行的前端项目
- 主界面6栋楼的点击导航
- 年级选择和用户信息存储
- 基础路由框架（主界面→各教学楼）

---

## 阶段验收标准
- [ ] 新用户可以完成注册→选年级→创建学校流程
- [ ] 主界面显示6栋教学楼，布局合理，风格统一
- [ ] 每栋楼点击可进入（先放占位页面也行）
- [ ] 左上角显示学生信息
- [ ] 响应式：1920宽屏和1024平板都能正常显示
