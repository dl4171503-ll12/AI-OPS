## 3. 测评流程

1. **起点**：按年级映射起点档（≤3 初级 / 4–6 中级 / 7–9 雅思预备 / 10–12 高级）。年级只是起点，**最终档位由作答决定**。
2. **四站**：听说·听 → 口语·说 → 读写·读 → 读写·写。
3. **自适应阶梯**：每站从起点档开始；该档通过则升一档，未通过则降一档；**每站最多 3 题**，档位不重复。
4. **雅思判定站（追加）**：满足触发条件后，追加雅思风格四单项（听/读/写/说各 1 题）。
5. **出报告**：四技能分数与到达档位、三簇分数（口语 / 听说 / 读写）、雅思起步判定、下一步建议。

### 雅思判定触发规则（防"硬塞雅思"）
- 起点在雅思预备及以上：**有任一技能考到雅思预备档，或四项平均 ≥50** 才追加；
- 起点在初级/中级：**必须真的考到雅思预备档**才追加；
- 初二学生全错（E2E 场景 A）：不追加雅思题，overall = 初级。

## 4. 评分规则（可判定、可解释）

| 题型 | 规则 | 通过线 |
|---|---|---|
| 客观题（听/读） | 选项完全匹配 → 100，否则 0 | =100 |
| 写作 | 长度比 0.4 + 关键表达命中 0.25 + 衔接词 0.2 + 有效句数 0.1 + 首字母大写 0.05 | **≥75** |
| 口语（转写文本） | 长度比 0.35 + 关键表达 0.25 + 衔接 0.15 + 有效句 0.1 + 词汇多样性 0.15 | **≥75** |

### 四条防越档设计（验收中踩出来的）
1. **连续升级**：到达档位 = **连续通过**的档位，不允许跳档。初级题做错却答对雅思题，不会判成雅思预备。
2. **开放题统一 75 通过线**：口语/写作一题即代表一档，原 65/70 的低线会被"长模板"越档（实测 69 分被判"到达高级"），已统一为 75。
3. **单题证据提示**：某档只有 1 题证据时，报告注明"建议复测或加题确认"。
4. **综合档位取四项最低（MIN）**：保守口径，避免用强项掩盖弱项。

### 雅思"能否开始真题"判定
- 单项阈值：听力 ≥65、阅读 ≥65、写作 ≥60、口语 ≥60。
- **一致性闸门**：四项综合没到雅思预备档时，即使四单项都过线，也**不判"具备真题水平"**，IELTS 区间估计压到 `4.0–5.0（上限）`。
  - 原因：验收时出现过"综合中级（A1~A2）却判 5.5–6.0、可刷真题"的自相矛盾，属于会被家长一票否决的硬伤。

## 5. 口语能力的诚实边界（必须让用户知道）

- 浏览器 **Web Speech API 只能把语音转成文字，不能做声学/音素评分**。因此口语分只计算：信息覆盖、句法、词汇多样性、衔接。
- **发音(pronunciation)不计分**，单独标注"需接入语音评测服务或由老师听录音复核"。录音本地留存，可下载。
- 已知风险（竞品报告 §differences-2）：通用 ASR 以"听懂"为目标，孩子把 `think` 读成 `sink` 也可能被转写成 `think`，导致**"发音越差越发现不了"**。
- Safari/iOS 不支持 Web Speech API → 回落到手动输入转写，此时分数会标注来源为"手动转写"（否则测的是打字不是说话）。

7. 雅思区间估计基于 4 题平均，只能作"区间参考"，不可当雅思成绩预测。

## 9.5 独立 HTML 测评（49 题版：分档题库 + 多维图表报告）

> 文件：`public/english-assessment.html`（单文件，零外部依赖；可 `file://` 双击打开，也可 `http://127.0.0.1:918/english-assessment.html`）
> 题库源：`public/items/{beginner,intermediate,ielts-prep,advanced}.json`（4 档 × 49 题 = **196 题**）

### 题量与难度阶梯
每档固定 **49 题**：词汇 12 + 语法 9 + 听力 6 段×2 题 = 12 + 阅读 2 篇×4 题 = 8 + 口语 4 + 写作 4 = 49。
每题带 `tier`：1=基础 / 2=达标 / 3=**本档封顶**；组卷时按 tier 从易到难排序，因此整场测评难度**从简单一路走到所选水平的最高级**（初级不越到过去时/被动，中级不越到第二条件句，B1 封在让步/虚拟/推断，B2 封在倒装虚拟/态度推断，均不到 C1）。
难度分布：初级 15/17/17、中级 15/17/17、雅思预备 18/14/17、高级 14/18/17（tier1/2/3）。

### 界面原则：只保留学生需要的东西
- **开始页**：只有 4 个水平选项（显示各自题数）+ 开始按钮，正文约 180 字。
- **答题页**：只有题目、作答控件（选项 / 输入框 / 播放音频）、进度条、保存 / 提交。**没有任何判定指标、日志、置信度或"反爬演示"**。
- 草稿纸、答题卡均为默认收起的折叠项，不进答题视野。
- 异常校验全部**后台静默**：界面不显示过程指标；只有触发异常时才出现"当前操作无法继续"并停止写入。

### 报告（多维图表）
提交后生成：总分与水平判定 → **六维能力雷达**（听力/口语/阅读/写作/词汇/语法，内联 SVG）→ **分项得分条形图** → **难度阶梯表现**（基础/达标/挑战三档正确率）→ **题目构成环形图** → 结论与建议 → 可展开的逐题结果。

### 题库生产与构建流程
```
public/items/*.json  ──validate──>  node scripts/validate-items.mjs <file>
                     ──build────>  node scripts/build-assessment.mjs
                                   → public/english-assessment.html（单文件，题库内联）
```
- 校验器强制：每档 49 题、六类题型数量、选项 3 个且不重复、answer 必须在选项中、tier1/2/3 各 ≥8。
- 内容规则：听力稿/题干/口语写作题为原创；阅读语料改编自公有领域（伊索寓言）或 Wikipedia/Simple English Wikipedia（CC BY-SA），并在 `source` 标注；不编造 URL。

### 评测有效性修正（v2，2026-11-10 返工）
初版词汇题出现过 `"I have a red ___." ball / bell / bill` 这类题：三个选项只差一个字母、且只有 ball 搭配得通，**学生不懂词义靠排除法就能选对，实际只考拼写**；而且当时只有听力题有音频，其他题学生不知道在问什么。已整体调整：

1. **词汇题改为考词义**：每题新增 `clue` 语义线索 + 三个**真实同词性、同语义场、词义不同**的选项。
   - 初级/中级：`clue` 用中文（如"它是圆的，可以用脚踢"），测英文词义。
   - 雅思预备/高级：`clue` 用英文释义/同义提示（如 `in a direct way; without anything in between`）。
2. **禁止拼写近形干扰项**：校验器对任意两个选项做编辑距离检查，**≤1 直接报错**（ball/bell/bill、tired/tiring/tire、reveal/release/refuse 这类已清零）。
3. **每题都能朗读**：所有题（词汇/语法/阅读/口语/写作）都有「🔊 朗读题目」按钮（听力题另有播放），中文线索不朗读，避免英文语音读中文。
4. **组卷交替题型**：同一难度层内按 词汇→听力→语法→阅读→口语→写作 轮转，避免连做 12 道词汇题。
5. **语法题歧义复核**：每档 9 题逐题确认"只有一个选项能填"；已修 `___ is my father`（He/She/It 歧义）、中级 i-g4（did/was doing 歧义）、高级 a-g7（mixed conditional 第二解）等。

校验器新增硬规则：`vocab` 缺 `clue` 或出现近形选项 → ❌；`grammar` 题干必须含 `___`。

### 9.6.1 完整测评的 MST 流程（已实现）

### 9.6.2 基准 + 进度监测（已实现，按 2026-11-10 决策）
- **快速基准测**：**24 题**（4 档 × 3 难度 × 2 题），约 12 分钟，跨等级同一量尺；**每 4 周一次**，首页显示上次时间与下次到期日。
- **成长曲线**：本地历史（最近 8 次）折线图，**纵轴为档位 A1→B2**（不是量尺分），家长可直接看懂"档位有没有升"。

### 9.6.3 诚实边界（重要）
1. **当前 49 题/档的题库撑不起标准 MST**：标准 MST 需要每阶段每难度独立模块（约 105 题/档，4 档共 420 题）。P0 用"贪心模块组装"过渡，同一次施测不重复用题，但**不同学生之间会共用题目**，且模块难度只能近似。

## 9.8 测评体系 v2.1：蓝思阶梯 + 雅思口语（已实现原型，**MST 已取消**）

> 规格：`docs/OPS_蓝思测评与雅思口语方案_v1.md`；MST 旧方案标记废弃：`docs/OPS_自适应测评架构_MST与进度监测_v1.md`

**结构**：阅读 = 蓝思阶梯（5 篇 × 4 题）→ 按正确率升/降难度 → 出蓝思值；口语 = 雅思 Part 1/2/3（6 题左右），难度按蓝思值选档。
- **阶梯规则**：≥75% 上 150L；≤50% 下 150L；中间上 75L；共 5 篇。蓝思估计 = 各篇 `篇蓝思 + (正确率−0.75)×200` 的均值，夹在 BR–1600L。
- **雅思口语五档**：<400L / 400–700L / 700–1000L / 1000–1300L / >1300L，决定 Part 1 题量、Part 2 时长、Part 3 题量与抽象度。
- **评分**：雅思四维 FC/LR/GRA 文本预估（0–9，0.5 步长）；P 发音接 Azure PA，未配置显示"待评测"。
- **报告**：蓝思值（±150L）+ 推荐阅读范围（+50L ~ −100L）+ 蓝思位置标尺 + 阅读阶梯路径 + 阅读技能（细节/推断/词义/主旨）条形+雷达 + 雅思口语 band 条形+雷达 + 逐段明细 + Azure 发音卡。
- **基准测**：3 篇 / 12 题 / 4 周，输出蓝思值；成长曲线纵轴为蓝思档。

**诚实边界**：蓝思值是基于题目难度的**估算**，不是官方 Lexile 测量（MetaMetrics 量表需授权）；题目标签未经官方 Analyzer 校对；雅思 FC/LR/GRA 是文本预估，非考官评分；P 依赖 Azure 密钥。

**验证**：`node scripts/e2e-lexile-assessment.mjs` → **44 项断言全过**（开始页无 MST、阶梯 5 篇、升降逻辑、蓝思值产出、雅思选档、报告 6 类图表、基准蓝思曲线、异常锁死、无 JS 异常）。
