# 学生使用手册（1.0）

1. 打开学校网站，输入名字、选头像与年级，点「创建我的学校」。
2. 校园里点击 **数学楼 / 语文楼 / 英语楼** 上课（其余楼为预览）。
3. 第一次进楼先做 **学情测评**，再生成 **今日任务**，去做 **练习题**。
4. 错题会进 **错题本**，可「重练同类」。
5. 找 **校长** 问本周安排；心情不好去 **心理咨询室**。
6. 完成今日任务后，**娱乐探索楼** 解锁；也可逛 **探索广场**。
7. 用邀请码在 **校际社交广场** 加好友，注意不要发手机号/微信。
8. 学习达标后可在设置或校园触发 **晋升仪式**，校园风格会升级。
