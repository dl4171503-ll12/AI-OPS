# AI一人学校 1.0 · 部署与运维说明

## 环境要求
- Node.js 18+
- 可访问 DeepSeek API（主）与可选 Moonshot/Kimi（备）

## 部署步骤（开发/内网演示）
1. 解压交付包
2. 确认 `.env` 含 `DEEPSEEK_API_KEY`（已迁移则无需改）
3. `npm install`
4. `npm run dev` → http://127.0.0.1:919/
5. 生产预览：`npm run build && npm run preview` → http://127.0.0.1:920/

## 数据存储
- 学生学情、错题、社交、情绪摘要等保存在浏览器 `localStorage`（键：`ai-one-person-school-v1`）
- 换设备需导出/迁移本地数据（1.1 可接 PostgreSQL）

## 运维注意
- AI 超时：检查密钥余额与网络
- 社交审核为本地规则引擎，可替换为云端审核 API
- 家长 PIN 默认 `1234`，务必在家长中心修改

## 端口
- 开发 919（避免与彩光AI 909 冲突）
- 预览 920
