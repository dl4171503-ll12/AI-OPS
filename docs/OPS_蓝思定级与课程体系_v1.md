# 蓝思定级与课程体系（v1，2026-11-11）

> 定级依据：本次测评的蓝思（Lexile）结果 + MetaMetrics 年级区间（25–90 百分位）
> 用途：确定学生当前级别 → 决定课程安排、选材范围、升级/降级规则

## 1. 蓝思定级表（L1–L5）

| 级别 | 名称 | 蓝思区间 | 对应年级 | 课程阶段 |
|---|---|---|---|---|
| **L1** | 蓝思初级 | BR–400L | 小学 1–3 年级 | 入门：字母/高频词/短句；绘本与分级读物 |
| **L2** | 蓝思中初级 | 400L–700L | 小学 4–6 年级 | 基础：短篇故事、日常对话；章节书入门 |
| **L3** | 蓝思中级 | 700L–1000L | 初一–初三 | 进阶：科普短文、记叙文；开始读写结合 |
| **L4** | 蓝思中高级 | 1000L–1300L | 高一–高二 | 熟练：说明文/议论文；长句与推断 |
| **L5** | 蓝思高级 | 1300L–1600L | 高三/雅思 | 高阶：学术文章、原著改写；观点与评价 |

**定级规则**：测评得到的蓝思值 `lex` 落入哪个区间，就定哪一级；区间边界向上取（如 700L 定 L3）。

## 2. 每个级别的"推荐阅读范围"

统一按业界规则：**学生蓝思值 +50L ~ −100L**。

| 当前蓝思 | 推荐阅读 | 说明 |
|---|---|---|
| 430L（L2） | 330L–480L | 略低于当前值，保证 90% 以上词能读懂 |
| 730L（L3） | 630L–780L | 逐步向 750L 试探 |
| 1050L（L4） | 950L–1100L | 非虚构为主 |

## 3. 课程安排（按定级生成）

每个级别：**4 周为 1 个单元，每周 3 课，每课 8 道小题（约 5 分钟）**。

| 周次 | 安排 |
|---|---|
| 第 1–2 周 | **重点突破最弱项**（按报告：听力/口语/阅读/写作之一） |
| 第 3 周 | 巩固：错题复习 + 同级别文章再练 |
| 第 4 周 | 综合：四项混合 + 升级检测（3 篇推荐区间文章，正确率 ≥75%） |

**选材规则**：
- 阅读：只从 `[lex−100, lex+50]` 的篇目里选（题库 32 篇，200L–1450L，覆盖 14 个百位档）
- 听力/听写：按定级对应的句子长度与语速（L1 短句 → L5 长句）
- 口语：朗读材料按级别缩短（L1 1–2 句，L2 3 句，L3+ 更长）
- 写作：按级别给字数与结构要求

## 4. 升级 / 降级规则

| 情况 | 处理 |
|---|---|
| 推荐区间内连续 **3 篇** 正确率 **≥75%** | **升一级**（L2→L3），推荐阅读范围随之上移 |
| 单篇正确率 **<50%** | 保持当前级别，**加 1 周复习**，文章降 100L |
| 连续 2 篇 <50% | **降一级**重练，避免挫败 |
| 每 4 周 | 用快速测复测蓝思值，更新定级与教案 |

## 5. 与教案/主页的联动（已实现）

- **报告页**：新增"蓝思定级"卡：级别、蓝思区间、对应年级、当前值、推荐阅读、距下一级的进度条、升降级规则。
- **教案**：`plan.lexLevel` 记录定级；教案"依据"写明定级与推荐区间；复习清单加入"读 3 篇推荐区间文章"。
- **学习课**：阅读题**只从当前定级区间选文章**（85% 概率），难度不跳级。
- **主页**：新增"蓝思定级"卡：Lx、区间、对应年级、当前蓝思、推荐阅读、进度条。

## 6. 诚实边界

- Lexile 是 MetaMetrics 的注册商标/量表，我们的蓝思值是**基于题目的估算**，不是官方 Lexile 测量；对外称"蓝思参考值"。
- 级别名称（L1–L5）是我们的课程分层，不是官方命名。
- 升级规则（3 篇 ≥75%）是教学规则，不是官方晋级标准；正式定级仍需官方测评或校准。
