# 测评插图规范（v1，2026-11-11）

> 目标：让低龄阅读题有"看得懂的图"，且**图必须忠实于故事**，不能画成与情节矛盾的内容。

## 1. 风格规则（产品要求）
| 年级 | 风格 | 提示词要点 |
|---|---|---|
| 1–3 年级（beginner） | **卡通** | 明快色彩、圆润可爱、白底、无文字 |
| 4–6 年级（intermediate）及以上 | **简笔画** | 黑色线条、白底、不上色、无文字、简洁清晰 |

## 2. 故事类文章：必须用"分镜脚本"，不能用摘要生成
**教训**：第一版用"中文摘要"生成《狮子与老鼠》，结果画成了"小老鼠在狮子怀里睡觉"——与故事完全相反（故事是老鼠爬过脸吵醒狮子、求饶被放走，最后狮子被网困住、老鼠咬网救它）。

因此 `scripts/illustration-scenes.mjs` 为每篇故事手写 5 个分镜（主图 + 4 张题图），按情节顺序，**最后一张是结局**。示例（狮子与老鼠）：
1. 大树下狮子睡觉，小老鼠跑来准备爬过它的脸
2. 小老鼠跑过脸，狮子被吵醒
3. 狮子按住老鼠，老鼠求饶，狮子笑
4. 狮子被绳网困住
5. 老鼠咬断网绳，狮子获救

## 3. 生成方式
```bash
# 全部故事分镜（会覆盖旧图）
node scripts/generate-illustrations.mjs --scenes-only --force

# 只重做某一篇
node scripts/generate-illustrations.mjs --scenes-only --force --only beginner-r1

# 非故事类文章的主图
node scripts/generate-illustrations.mjs --mains-only
```
- 输出：`public/illustrations/*.jpg` + `manifest.json`（key：`p:<文章id>` / `q:<文章id>:<题号>`）
- 页面渲染：`node scripts/build-assessment.mjs`
- 成本：`image-01` 约 $0.0035/张；整套 32 主图 + 低中年级题图约 ¥2–3。

## 4. 验收清单
- [ ] 1–3 年级：主图与每题都有图，且是彩色卡通
- [ ] 4–6 年级及以上：主图与题图是黑白简笔
- [ ] 故事类：5 张分镜能连成完整情节，结局图正确（如狮子获救）
- [ ] 图中无文字（避免英文拼写错误干扰）
- [ ] 图片缺失时回退 emoji，不出现破图
- [ ] 末篇（最难）仍可保留插图，但不再显示中文题意
