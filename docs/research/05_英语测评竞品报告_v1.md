## 1. 摘要（先给结论）

**一句话：我们的英语测评在"分档结论的可解释性 + 家长可读性"上是竞品里少见的，但在"口语到底怎么给分"这一件事上，我们处在这条产业链的最底端——用的是浏览器转写文本 + 规则打分，而这条产业链的头部（讯飞/微软/SpeechAce）用的是音素级声学模型，且已大规模用于中高考正式评分。**

八条判断：

1. **口语评分的分野不是"AI vs 人"，而是"有没有声学信号"。** 微软 Pronunciation Assessment 的准确度分是**音素级**映射而来（`AccuracyScore` 由音素级汇总并 refinement），讯飞英文句子/篇章评测同样给"准确度+流畅度+完整度"三项，且**已大规模用于全国中高考英语听说考试正式评分**、提供**音素级**逐词标注。✅ 我们的 Web Speech API 只能拿转写文本 → **发音维度在原理上不可测**，这不是"没做完"，是"路线不同"。
2. **"没有发音分"作为入学分档器可以接受，作为考试提分工具是硬伤。** 分档只需要判断"能否理解与表达"；但北京中考英语 100 分里有 **40 分是听说机考**，题型含**短文朗读、听后转述**——这两项的本质就是发音与流利度。✅ 一旦我们要卖"中考提分"，无发音分立刻变成致命缺陷。
3. **最危险的漏洞不是"没有发音分"，是"转写会抹平发音错误"。** 通用 ASR 会把非母语的错误发音"归一化"成正确单词，于是"发音很差但转写正确"→ 规则打分给出高分。微软为此专门使用**区别于通用 STT 的评测模型**并返回 NBestPhonemes（同音候选置信度），就是在解决这件事。⚠️ 我们目前没有任何检测手段。
4. **DET 用 IRT + 计算机自适应，我们用"4 档阶梯"。** DET 官方说明：每个题目的难度参与计分，不同考生拿不同题组仍可比（IRT）。我们只有 4 个档位 × 每档 1 题，**分辨率只有 4 级，且无难度参数、无等值**。差距不在算法，而在"题目参数与样本校准"这件事我们还没开始。
5. **"每档 1 题"是信度硬伤，但可修，且很便宜。** 我们在代码里已经用"该档仅 1 题证据，建议复测或加题确认"兜底（`english-assessment.ts:702`），这是诚实的；但正确做法是"每档 ≥2 题 + 2/3 决策规则"，成本只有题库扩容。
6. **"只给目标不给进度"在测评场景是反行业的。** 调研范围内**没有任何一家**在测评报告里隐藏进度：DET 给总分 + 4 个单项 + 4 个整合分项；Amira 给 raw/标准分/百分位/年级当量/IRT 分/Lexile；i-Ready 给 placement level + percentile；讯飞给逐词音素级。✅ 建议：**学习场景隐藏进度（保留我们的原则），测评报告场景必须给"目标 + 距离 + 证据"**。
7. **定价上，测评不该单独卖。** DET 单次 $65（🔶 第三方口径）是一次性高风险考试；Amira 学校采购 **$8/学生/年**（评测套件）到 **$20/学生/年**（全量+AI 辅导）；流利说优选套餐 ¥1099/半年、¥1996/年（第三方渠道页）。我们的测评应做**免费获客 + 报告付费/诊断付费**，而不是 ¥99 卖一次测评。
8. **我们真正的差异点只有一个，且很值钱：把"测评"和"四步引导教学法"接在一起。** 竞品的测评几乎都止于"报告"，下一步动作靠人（老师/家长）。我们的报告直接产出 `nextSteps`（如"每天 3 分钟先说后写，固定三句式"），这是从"测量"走向"处方"的一小步，但方向上领先——**前提是处方要更具体、可验证**。

## 3. 分品类拆解（三栏：① 做得好 ② 缺陷 ③ 颠覆性）

### 3.1 Duolingo English Test（DET）

**① 做得好（我们该借鉴）**
- **分数结构公开且自洽**：4 个单项分（R/W/L/S）+ 4 个整合分项（Literacy=R+W、Comprehension=R+L、Conversation=S+L、Production=S+W），整合分 = 两个单项分的简单平均，总分 = 四项单项平均后**按 5 分取整**。✅ 这套结构对家长极度友好——"你孩子听读强、说写弱"一眼能看懂。我们的"三簇（口语/听说/读写）"是同类思路，但**没有单项→整合的算术定义**，家长无法自行核对。
- **把"我为什么可信"写成产品**：IRT 让不同题组可比；AI 评分模型用专家评分样本训练；有人工监考、跑题/乱码标记、非英语回答自动判定作废、跨人群公平性检验、AQuAA 实时监控。✅
- **区分"规则评分"与"模型评分"**：读/听用结构化规则（不是 ML），说/写才用模型——这条工程纪律值得学：**能规则化的绝不上模型**。

**② 缺陷（不如我们）**
- **它是一张"入场券"，不是"教学方案"。** 出分即结束，没有"下一步 12 周怎么练"。我们的报告直接给 `nextSteps`。
- **无"学校治理"层**：没有校长、没有多学科，家长拿到 160 分也不知道该先补什么。
- **$65 一次、有重考冷却**，对 6–12 岁家庭是"高风险考试"，不是"日常体检"。

**③ 颠覆性**
它证明了**"AI 可以把高风险语言考试的成本砍到 1/4"**（$65 vs TOEFL 约 $245，🔶 WitPrep 2026 标题口径），并把"自适应 + IRT + 自动化评分"变成行业默认标准。**它颠覆的不是教育，是考试产业。**

### 3.2 Duolingo App

**① 做得好**：把测评藏进游戏循环（每个单元即时判定，用户感知不到"被测评"）；streak/XP 制造日常回归。
**② 缺陷**：它的"测评"是**形成性**的，不出可解释的能力诊断；不能作为入学分档依据。我们做的是**终结性 + 可解释**，这是两种东西。
**③ 颠覆性**：它证明"每天 5 分钟 + 情绪角色"的留存可以打穿所有教学法争论。对我们的启示是：**入学测评必须短到像游戏，否则家长第一周就流失。**

### 3.3 Amira Learning（朗读流利度 ASR 评分）

**① 做得好（最值得抄的一家）**
- **极致的产品化**：学生对着屏幕朗读，**4 分钟/人**，全自动评分，软件自己当"监考"（引导流程、检测软硬件问题）。✅
- **分数体系完整到"可以直接进 IEP"**：raw / 标准分 / 百分位 / 年级当量 / **IRT 分** / Lexile / 错误分析 / 综合分 / 子分。✅
- **价格低到反常识**：评测套件 **$8/学生/年**、全量套件（含筛查 + 进展监测 + 教师报告 + AI 辅导）**$20/学生/年**，批量还有折扣。✅
- 覆盖 6 个维度（口语语言、音素意识、拼读、流利度、词汇、理解），K–6，西语版全套可用，WCAG 2.0 AA、SOC 2 Type 2。✅

**② 缺陷**：只做阅读（不覆盖说/写）；只服务学校（不面向家庭）；无中文语境（不解决中考听说）。
**③ 颠覆性**：它把"老师一对一监听朗读"这个最贵的动作，做成了 **$8/年** 的边际成本——这是对我们"AI 老师替代人力"最强的一记证明，也是最强的成本压力：**如果我们的口语评测成本高于这个量级，商业模型就站不住。**

### 3.4 ELSA Speak / SpeechAce（发音评测基础设施）

**① 做得好**
- **SpeechAce 把"分档换算"这件事做成 API**：scripted（有参考文本，加 fluency/lexical stress/intonation）与 spontaneous（自由说，转写+发音+语法+词汇+连贯+相关性+语种检测）双模式；`score/task` 直接给"任务完成度"；`score/writing` 评写作。✅
- **SpeechAce 官方给了一张对照表**：IELTS / CEFR / PTE / TOEIC / Speechace 五套分数区间并列（例：IELTS 5.5 ↔ CEFR A2+ ↔ PTE 42 ↔ Speechace 58–63；IELTS 7.0 ↔ B2 ↔ PTE 68 ↔ 75–80）。✅ 这张表可以直接拿来校准我们的"雅思区间估计"。
- ELSA 走的是"音素级发音诊断 + 逐词纠音"的 C 端路线。🔶

**② 缺陷**：它们是"零件"不是"整车"——没有课程、没有学情档案、没有家长报告。对我们不是竞品，是**供应商**。
**③ 颠覆性**：把"发音打分"从学术能力变成**一个 API 调用**。这意味着我们补发音分不需要自研模型，只需要钱和一次集成决策。

### 3.5 Ello / Speak

**① 做得好**：Ello 用"朗读识别 + 自适应级别"做 5–9 岁阅读，把"读错立刻纠正"做成体验；Speak 用对话式 AI 做口语，2024-12 完成 7800 万美元 C 轮、估值 10 亿美元（Accel 领投，OpenAI Startup Fund 早期投资）。✅
**② 缺陷**：单一技能、单一场景；Speak 主力是成人口语，与 6–18 岁课内体系不兼容。
**③ 颠覆性**：Speak 证明了**"口语这一件事就能撑起 10 亿美元估值"**——口语是英语学习里最刚需、最缺人、最容易被 AI 替代的环节。

### 3.6 i-Ready / Renaissance / Raz-Plus / Lexile / AR（美国测量基础设施）

**① 做得好**：一整套"自适应诊断 → placement level/百分位 → 分级阅读 → 进展监测"的闭环；**分数之间可以互相换算**（IRT 分、Lexile、年级当量、百分位），教师看得懂、学区敢采购。i-Ready 诊断是自适应、不限时的在线测验，输出 placement level 与 percentile（2026–27 学年仍有大量家长指南在解释这套分数）。🔶
**② 缺陷**：全部面向英语母语者（Lexile/AR 是"阅读难度"不是"二语能力"）；无口语；不进中国课标。
**③ 颠覆性**：**"分级 + 换算"本身就是产品**。它让"你孩子相当于几年级"这句话有了可辩护的依据——这正是我们最缺的（我们的"档位"目前只有 4 级且无外部锚点）。

### 3.7 剑桥 YLE / A2 Key / B1 Preliminary（数字化）+ 雅思官方练习

**① 做得好**
- **命名与路径极清晰**：YLE → A2 Key（原 KET）→ B1 Preliminary（原 PET）→ B2 First → C1 Advanced → C2 Proficiency；"for Schools" 版仅话题不同，难度与证书效力完全相同。✅
- **数字化在快速铺开**：剑桥在 **130 个国家 2800 余个考点**提供数字化考试；**成人版 A2 Key 纸笔考试将于 2026 年 6 月后停止，仅保留机考**；A2 Key for Schools 纸笔保留。✅
- **诚实**：新东方明确写"上表是 CEFR 等级层面的区间对照，用于判断能力发展阶段，**不是精确的分数等值关系**"。✅ 这种免责表述值得我们照抄。
- 价格机制：**中国大陆 KET/PET 无全国统一价，由各授权考点自定**；证书长期有效。✅

**② 缺陷**：考试周期长、费用高、对低龄不友好；口语仍是真人考官（机考为录音后评），无法即时反馈。
**③ 颠覆性**：**它把"能力"变成了全球通用的货币**。家长愿意为"一个证书等级"付钱，而不是为"一个分数"付钱——这是我们分档体系的商业化机会（"你的孩子已达 A2 Key 水平"比"你得了 62 分"更有说服力）。

### 3.8 国内：讯飞 E听说 / 中高考英语听说机考系统

**① 做得好（这一组是我们的天花板）**

- **附带作文批改**：拍照上传手写作文，即时给拼写、语法、用词、篇章结构多维分析，标准与中高考书面表达一致。✅
- **评测维度定义清晰**（讯飞开放平台文档）：英文**单词**题型给"总分 + 准确度"；英文**句子/篇章**题型给"总分 + 准确度 + 流畅度 + 完整度"，并且**每个分句**给准确度/流畅度、**每个单词**给分；支持自定义音标（可指定美音/英音）、支持 **11 类异常检测**（乱说英文、乱说普通话、纯音乐、咳嗽、敲键盘、敲桌子、乱说方言、触碰话筒、唱歌、聊天、吹气）+ 音质异常（音量过小/截幅/低信噪比），返回 `is_rejected` 与异常码。✅

**② 缺陷（我们相对它的机会）**
- 它是**"考试训练器"**：驱动逻辑是"提分"，不是"理解孩子"；没有跨学科、没有心理支持、没有"一人一所学校"的叙事。
- 它是**硬件/校内绑定**：家庭侧要买学习机或等学校采购，价格 2–3K 起（见 04 报告 AVC/IDC 数据）。

**③ 颠覆性**：**它把"口语考试"从一个需要考官现场打分的环节，变成了全年 67 亿次的算力调用。** 这直接摧毁了"英语口语只能靠外教"的成本结构。对我们而言，它既是技术天花板，也是**最强的合作/采购候选**——补发音分最快的路径就是买它或同级服务。

## 4. 五大深度点

### 4.1 口语自动评分到底怎么实现的？我们"无发音分"是硬伤还是可接受？

**产业现状（三条技术路线）：**

| 路线 | 代表 | 输入 | 输出 | 是否需要参考文本 |
|---|---|---|---|---|
| A. 通用 ASR 转写 + 文本规则 | **我们** | 音频 → 文本 | 信息/句法/词汇/衔接 | 否 |
| B. 专用评测 STT + 音素对齐 | 微软 Pronunciation Assessment | 音频 + 参考文本（scripted）或无参考（unscripted） | **Accuracy / Fluency / Completeness / Prosody**，可下钻到音节与音素 | 可选 |
| C. 专用声学模型 + 音素级打分 | 讯飞 ISE、SpeechAce、ELSA | 音频 + 文本/音标 | **总分 + 准确度 + 流畅度 + 完整度**（中文/英文题型不同） | 是（scripted） |

**关键细节（都能查到原文）：**
- 微软：`AccuracyScore` 衡量音素与母语者的接近度，音节/词/全文分**由音素级汇总并 refinement**；`FluencyScore` 衡量"停顿是否像母语者"；`CompletenessScore` = 已发音词数 / 参考文本词数；`ProsodyScore` 含重音、语调、语速、节奏（仅 en-US）；粒度可选 Phoneme/Word/FullText，返回 IPA 或 SAPI 音标、音节组、以及 **NBestPhonemes**（该音素的候选发音及置信度，如把 /ɛ/ 读成 /ə/ 时给出 5 个候选）。`PronScore` 是**"短板优先"加权**：有韵律分时 `0.4×最低分 + 0.2×次低 + 0.2×第三 + 0.2×最高`。✅
- 讯飞：英文句子/篇章题型给 **总分、准确度、流畅度、完整度**，每个分句给准确度/流畅度，**每个单词给分**；支持在试卷里标音标指定发音（多发音用 `|` 分隔）；返回 `dp_message` 中 16=漏读、32=增读（miscue 思路）；并有 `is_rejected`（乱说拒识）。✅
- SpeechAce：scripted 模式额外给 **fluency、lexical stress、intonation**；spontaneous 模式给 pronunciation/fluency/grammar/vocabulary/coherence。✅

**结论（分场景）：**
- **作为"入学分档器"：可接受，但必须继续说清。** 因为分档要回答的是"能不能听懂/读懂/说成句"，文本四维足以支撑 4 档粗分。我们代码里的 `pronunciationNote` + 页面文案（"发音维度未计入分数，录音留存供老师复核"）是**正确的诚实做法**，比"用声学模型随便给个分"更负责。
- **作为"考试提分/口语教练"：是硬伤，且是结构性的。** 北京中考英语听说 40 分、四题型中有 **短文朗读** 和 **听后转述**，这两项主要看发音可懂度与流利度；讯飞的技术已直接用于这类考试的正式评分。没有发音分，我们在这个赛道连"入场"都做不到。
- **最该立刻修的隐藏风险：ASR 归一化。** 通用 ASR 的目标是"听出你想说什么"，不是"听出你怎么发音"。孩子把 think 读成 sink，ASR 可能仍转写为 think（语言模型纠错）→ 我们的文本规则给满分。**这会造成系统性的"发音越差越不容易被发现"的假象**。微软专门使用"评测专用 STT 模型"并返回同音候选，正是为了对抗这一点。

### 4.2 分档依据：CEFR / Lexile / 剑桥 / i-Ready / DET 怎么换算？可靠吗？

- **CEFR 是"能力描述框架"，不是"分数刻度"**。所有人（剑桥、雅思、SpeechAce、DET）都是在"区间映射"，没有任何官方的一对一换算。新东方在 2026 年的 KET/PET 指南里明确写："上表是 CEFR 等级层面的区间对照……**不是精确的分数等值关系**"，并提醒"雅思官网已明确原有托福–雅思对照关系仅适用于 2026 年 1 月之前的托福成绩"。✅
- **不同机构的映射互相打架**。SpeechAce 官方表：IELTS 5.5 ↔ CEFR **A2+**、6.0 ↔ **B1**、6.5 ↔ **B1+**、7.0 ↔ **B2**；而市场常见口径（以及我们代码里 `advanced` 档写的"雅思 5.0–5.5 ↔ B1+~B2"）与这张表并不一致。✅ 这不是谁错，而是**映射本身不稳定**——结论：**任何"我们相当于雅思 X"的表述都必须带区间 + 免责声明**。
- **DET 用 10–160 连续分 + IRT**，天然比 4 档细；它靠"题组难度参与计分"实现跨题组可比。我们的 4 档是**名义量表**，不能做加减，也不能跨版本比较。
- **Lexile / AR 是阅读难度，不是二语能力**：Lexile 衡量文本难度与读者水平，AR 用 ATOS book level；它们可以辅助"阅读材料选级"，但**不能直接回答"这个孩子英语什么水平"**。
- **i-Ready 走的是"量表分 + placement level + 百分位"**，Amira 走"IRT 分 + 年级当量 + Lexile + 百分位 + 错误分析"——共同点是：**永远给"绝对分 + 相对位置"两套**。我们目前只有绝对档位，缺"相对位置"（同龄百分位）。

**对我们最实用的三条**：
1. 保持"课标一级/二级/三级"作为**主锚**（中国家长和学校真正认这个）；
2. CEFR / 剑桥级别 / 雅思作为**辅助锚**，一律写"参考区间"；
3. 增加"同龄参考"（不用百分位也可以先给"同年级常见档位"），这是家长最想知道的一句话。

### 4.3 自适应测评：DET/Amira 的算法 vs 我们"1 题/档阶梯"

| 维度 | DET | Amira | 我们 |
|---|---|---|---|
| 算法 | 计算机自适应 + **IRT** 计分（题目难度参与能力估计） | 自适应 + IRT 分 | **规则阶梯**：起点=年级 → 通过升一档 / 未通过降一档 |
| 题量 | 多题、按能力动态选 | 每个任务 4 分钟 | 每技能 **≤3 题**，每档仅 1 题 |
| 分辨率 | 10–160（5 分增量） | 量表分 + 年级当量 + 百分位 | **只有 4 个档位** |
| 等值 | 有（跨题组可比） | 有（跨版本） | 无 |
| 停止规则 | 能力估计收敛 | 达标即停 | 3 题封顶 / 档位重复即停 |
| 信度保障 | 大规模校准 + 公平性检验 | 州级筛查准入 | **单题证据，标注"建议复测"** |

**差距的本质不是"算法不够聪明"，是"我们没有题目参数"。** IRT 需要：① 每题的难度/区分度参数（b/a）；② 足够大的作答样本做校准；③ 等值设计。这三样我们都没有，所以**短期不可能上 IRT**。

**但可以立刻做三件"伪 IRT"的事**：
1. **教研先验难度**：给每题标 1–5 难度（我们已有 `difficulty` 概念但题库未用），分档判定改成"难度加权通过率"；
2. **每档 ≥2 题 + 2/3 规则**：单题判定的错误率太高，两题能显著改善；
3. **记录 `itemId + band + passed + score` 的历史**（我们已存 `StoredEnglishExam`），**先攒数据**，等有 500+ 学生再谈参数估计。

### 4.4 呈现方式：有没有人做到"只给目标不给进度"？家长报告长什么样？

**调研结论：没有一家做到"完全隐藏进度"，而且它们刻意相反。**
- DET：给总分 + 8 个分项（4 单项 + 4 整合），并明确"帮助考生知道该练什么"。
- Amira：给 raw/标准分/百分位/年级当量/IRT/Lexile/错误分析，**给老师用**。
- i-Ready：placement level + percentile。
- 讯飞：逐词音素级反馈 + 掌握度。
- Duolingo：进度条 + streak 是核心机制。

**它们的报告长什么样（共性）**：
① 一个"绝对分"（让人有位置感）→ ② 一组"分项"（让人知道差在哪）→ ③ 一个"相对位置"（年级/百分位，让人知道和别人比）→ ④ 一句"下一步"（多数很弱，通常只是"继续练习"）。

**我们的报告**：四维技能条 + 三簇（口语/听说/读写）+ 优势/待补/下一步 + 单题证据标注 ✅ ——**在第 ①②④项上不输，在第③项（相对位置）缺失，在第④项（下一步）上领先，因为它具体到动作**（"每天 3 分钟先说后写，固定三句式：是什么—为什么—例子"）。这是代码 `gradeEnglishExam` 里真实存在的内容。

**关于"只给目标不给进度"的判定**：
- 作为**学习页**的设计原则：合理（避免优越感/松懈），行业里没有对照，属于我们的独立主张；
- 作为**测评报告**的设计原则：**危险**。测评的付费方是家长，家长的核心诉求是"我现在在哪、离目标多远、凭什么这么说"。隐藏进度会让报告显得"没信息量"，也无法支撑复购。
- **建议**：分级处理——学生端学习页隐藏进度（保留原则）；学生端测评结果给"目标 + 距离 + 证据"；家长端给完整数据。这不是妥协，是把"防优越感"和"建立信任"分配到不同界面。

## 5. 我们测评的差距清单（按优先级排序，诚实版）

| # | 差距 | 性质 | 证据/根因 | 影响 | 修复成本 |
|---|---|---|---|---|---|
| 1 | **无发音声学评分** | **硬伤（考试场景）** | 代码注释与页面均标注"浏览器无法做声学评分"；产业侧微软/讯飞/SpeechAce 均为音素级 | 不能卖"中考听说提分"；口语报告缺最关键一维 | 中（接 API） |
| 2 | **ASR 归一化抹平发音错误** | **硬伤（隐蔽）** | 通用 ASR 以"听懂"为目标；微软专门用评测专用模型 + NBestPhonemes | 可能"发音差反而得高分"，报告失真 | 中（换专用评测） |
| 3 | 每档仅 1 题 | 高（信度） | `nextBandForSkill` 每档取 1 题；`itemsFor(skill,band)[0]` | 单题判定噪声大，同一学生两次测试可能不同档 | **低**（加题） |
| 4 | 规则阶梯非统计模型 | 高（分辨率） | 只有 4 档、无难度参数、无等值 | 无法给"档内差异"，无法跨版本比较 | 高（需校准数据） |
| 5 | 阈值无标准参照 | 中 | 雅思侧 L65/R65/W60/S60 为教研初值；开放题（口语/写作）通过线**已统一为 75**（原口语 65 / 写作 70 不一致已修） | 判定标准仍缺常模，家长质疑时需靠"初值"说明 | 低（补常模） |
| 6 | Overall 取 MIN（短板决定） | 中 | `overallIdx = Math.min(...indices)` | "口语弱、读写强"的孩子被整体压到最低档 | **低**（改呈现） |
| 7 | 口语规则可被"碰词"刷分 | 中 | `targets` 命中即得分；`connectives` 硬编码 10 词；TTR/0.6 在短文本不稳 | 分数与真实表达质量相关性弱 | 低（加权重/加长度门槛） |
| 8 | 雅思区间估计基于 4 题平均 | 中（过度宣称风险） | `avg>=80 → 5.5–6.0` 等 4 段映射 | 家长可能当作"雅思成绩预测"，反噬 | 低（改措辞+免责） |
| 9 | Safari/iOS 无 Web Speech API | 中（样本偏差） | 页面 `asrSupported=false` 时回落手动输入 | iPad 用户测的是"打字"不是"说话"，数据被污染 | 低（标注设备+排除） |
| 10 | 无"相对位置"（同龄/百分位） | 中 | 报告无 percentile | 家长少一个最想要的参照 | 低（先给"同年级常见档"） |
| 11 | 无异常作答检测 | 中 | 无静音/离题/照读/乱说判定（讯飞有 11 类） | 无效证据被当作有效分 | 低（静音+词数+离题检测） |
| 12 | 无效果证据 | 高（长期） | 无信度/效度研究 | 无法说服学校/机构 | 高（需样本） |
| 13 | 无难度参数与题库深度 | 中 | 每档只有 1 题，无 b 值 | 未来上 IRT 无基础 | 中（题库+标定） |

**一句话总结差距**：**我们的"报告层"是竞品里的中上水平，"评分层"是入门水平，"证据层"是零。** 报告层最容易讲出差异，评分层最容易被打穿，证据层最难补但最值钱。

## 8. 英语测评下一步改进优先级

> 判断标准：**两周内能不能做完**。"两周可做"=2 人×5 工作日，不改动外部依赖。

### P0（两周内必须做完，4 条）

**P0-1｜口语补 3 个"零成本流利度"指标（不需要声学模型，当天可做）**
`MediaRecorder` 已有 `durationMs`，ASR 已有词数——直接算：
- **语速 wpm** = 词数 / (音频时长/60)；
- **首字延迟** = 录音开始到第一个识别结果的时间差；
- **停顿比** = 识别结果时间戳间隔 >1.5s 的总时长 / 音频时长。
写入 `ItemScore.detail`，口语总分加一条 `流利度(时长) 权重 10%`，其余维度等比下调。
**为什么优先**：这是唯一能"绕开声学模型"拿到真实口语信号的路径，且直接对标讯飞的"流畅度"概念（虽不等价）。
**两周可行性**：★ 可做（约 2 人日）。

**P0-2｜每档加 1 题 + 2/3 决策规则**
题库从"每技能每档 1 题"扩到 2 题（16 → 32 题，全部原创），判定改为"2 题中 2 通过才升级，1 通过保持，0 通过降级"；`evidenceAtBand` 门槛从 ≤1 升到 ≤1 仍提示，但升级需 ≥2 题证据。
**为什么优先**：差距清单里"信度"是唯一"低成本高收益"的项。
**两周可行性**：★ 可做（内容 3 人日 + 代码 0.5 人日）。

**P0-3｜总分从"MIN 短板"改为"加权 + 短板单列"**
`overallIdx = Math.min(...)` 改为：按四维加权分排序取中位数档位，同时在报告里单列"最弱维度（决定是否需要降档练习）"。
**为什么优先**：现在的实现会让"口语弱"直接吞掉"读写强"，家长第一反应是"测不准"，这是最伤的体验。
**两周可行性**：★ 可做（0.5 人日）。

**P0-4｜加"异常作答检测 + 证据等级"**
三件事：① 静音/词数极低 → 标 `invalid`（不给分）；② `targets` 全未命中 → 提示"可能离题"；③ 把现有的"仅 1 题证据"升级为三级标签（弱/中/强：题数 + 该档通过数）。
**为什么优先**：讯飞的 `is_rejected` + 11 类异常说明这是行业标配；我们目前会把无效作答当有效分，污染后续所有统计。
**两周可行性**：★ 可做（1 人日）。

### P1（4–6 周，3 条）

**P1-1｜接入云端语音评测，补"发音 + 流畅度"真分**
两条路：① 微软 Pronunciation Assessment（`AccuracyScore` 音素级、`ProsodyScore`、`NBestPhonemes`，英文句子/篇章场景成熟）；② 讯飞 ISE WebAPI（准确度/流畅度/完整度、音素级、支持自定义音标、11 类异常检测）。**先用 30 条真实录音做一致性 + 成本测试**（每条音频调用成本 × 每月测评人数 = 新增成本）。**iOS/Safari 改为"录完上传"而不是实时 ASR**，同时解决 P0 之外的设备偏差问题。
**为什么是 P1 不是 P0**：需要商务/密钥/合规确认，两周内无法稳定上线。
**验收**：口语报告出现"发音 0–100 + 最差 3 个音素"，并与老师人工评分做一次 20 例相关性对比。

**P1-2｜加"短文朗读 + 听后转述"两题型（对齐北京中考四题型）**
北京中考听说 40 分四题型：听后选择、听后回答、听后转述、短文朗读。我们已有"听后选择"，补后两类即可覆盖 100% 题型。朗读题走 P1-1 的评测引擎；转述题先做"信息点覆盖 + 长度 + 流利度"三项规则分。
**为什么值得**：这是国内唯一"政策强制、家长付费意愿刚性、竞品已验证"的窄口。
**验收**：一套 30 分钟"机考模拟"，输出与北京中考一致的题型结构与建议。

**P1-3｜输出"能力值 0–100 + 区间"而非单一档位，并写死免责话术**
用"档位 + 档内得分"插值成 0–100 能力值（例如 A1 档内 0–25 → 能力值 25–50），给出 ±8 的区间；报告固定一句："档位与雅思/剑桥为参考区间，不构成成绩预测"，对齐剑桥/新东方的表述纪律。
**两周可行性**：代码可做，但需教研确认插值规则 → 放 P1。

### P2（季度级，2 条）

**P2-1｜校准研究：50 人样本 vs 教师人工评分**
用同一批录音/作文，请 2 位英语老师独立按我们的维度打分，算相关系数与加权 kappa；目标是**证明"我们的口语分与人工评分至少中等相关"**。哪怕结果不好也公开——这是唯一能让学校/机构愿意谈的东西。
**为什么 P2**：需要招募样本与人工成本，两周做不完，但**这是第 5 节里"证据层为零"的唯一解**。

**P2-2｜题库扩容到"每档 3 题 + 难度先验"，为 IRT 铺路**
给每题标 1–5 难度（教研先验），`english-assessment.ts` 的 `EnglishItem` 加 `difficulty: number` 字段并写入所有历史记录；等累计 500+ 份 `StoredEnglishExam` 后，做第一次难度参数估计。
**验收**：字段落地 + 后台能导出 `itemId × difficulty × correctRate` 报表。

### 最后一句判断

**这套测评作为"入学分档 + 家长沟通工具"已经够用，甚至比多数竞品更会说人话；但作为"英语能力测量工具"，它现在缺的不是模型，是"证据"——发音的证据、信度的证据、效度的证据。补发音要花钱（P1-1），补信度只需加题（P0-2），补效度只需一次 50 人的研究（P2-1）。三件事里，有两件在两周内就能开始。**
