## 0. 一句话结论

**没有任何一个系统在所有维度上最好。** 全球真正"测得好"的第一梯队是 6 个：**IELTS（可信度天花板）、DET（可得性+自适应+CEFR 外部验证）、PTE（机器评分信度）、Pearson Versant（口语机评）、TOEFL（院校认可度）、WIDA/MAP（K-12 测量）**。
但**"6–18 岁、低龄到高级、四技能、要能和教学衔接"这一整套，市场上买不到**——必须"国际系统做锚 + 自研低龄与教学衔接 + 采购口语引擎"三层组合。

## 1. 按等级段：从初级到高级，谁测得好

### 1.1 初级 A1–A2（小学段）

| 首选 | 依据 | 代价 |
|---|---|---|
| **TOEFL Primary（Step 1/2）** | **唯一同时给 CEFR 与 Lexile 的国际低龄测评**；星级/徽章对儿童友好；Step1/Step2 两段难度 | 只有 4–5 档分辨率；非自适应；口语独立加试；需考点 |
| **剑桥 YLE + A2 Key for Schools** | 家长认知度最高；for Schools 与成人版效力相同；证书终身有效 | 口语人评为瓶颈；纸笔在退场 |
| （低成本粗筛）**EF SET Quick Check** | 15 分钟、免费 | 只测读+听，非自适应，只给 low/mid/high |

- **不要用**：IELTS / TOEFL iBT / PTE（A1–A2 段不可测或不适龄）；HMH Reading Inventory（**已停售**，2024-06 后不卖新许可）。
- **行业空白**：没有产品同时做到"6 岁愿意做 20 分钟"和"输出 CEFR 级 + 单项诊断"。这是最大的机会窗口。

### 1.2 中级 B1–B2（小学高年级–高中）

| 首选 | 依据 | 代价 |
|---|---|---|
| **TOEFL Junior（+ Speaking）** | 11–15 岁专门设计；总分 600–900 区分度足够；成绩单带 CEFR 与 Lexile；Speaking 有官方 CEFR 分段（11–13=B1、14–16=B2） | 口语人评贵；无自适应；考位有限 |
| **剑桥 B1 Preliminary → B2 First** | 与 A-Level/IB 申请衔接清晰；量表 102–190 覆盖 B1–C1 | 无自适应；人评；费用与考位 |
| **DET（100–125 = B2；130–150 = C1）** | CEFR 经 ACS Ventures + CIOL 外部验证（3,586 人双成绩一致性）；IRT 自适应；便宜快 | 顶尖院校认可度弱于 TOEFL/IELTS；低龄适配差 |
| **EnglishScore（300–399=B1、400–499=B2）** | 重测信度 **0.82–0.90**（低价工具里唯一公开）；CRELLA 做标准设定；**US$14/人次**含证书 | 只到 C1，无 C2；口语是加购 |

### 1.3 高级 C1–C2（学术/职场）

| 首选 | 依据 | 代价 |
|---|---|---|
| **IELTS Academic** | **复合信度 0.97、复合 SEM 0.17 band**；听力 alpha 0.90、学术阅读 0.92；口语人评质量体系（考官复训 + 锯齿分自动重评） | 贵、慢（纸笔 13 天）；A1–A2 不可测 |
| **TOEFL iBT（2026 新版）** | 院校认可度天花板；2026 起 **1–6 分段（0.5 递增）**，单项与总分同阈值（4=B2、5=C1、6=C2）；改为 **MST 多阶段自适应** | ETS 自认新表"更粗"，**不适合精细排位**；贵、考位紧 |
| **PTE Academic** | 总分信度 **0.93**（2024 增强版现场测试）；全机器评分；A2–C2 误差 4.1–7.0 分 | 口语是"对麦克风"，交互性弱；高分端误差大 |
| **剑桥 C1 Advanced / C2 Proficiency** | 量表 142–210 / 162–230；学术与职场双认可 | 人评、考位、考生基数小 |

## 2. 「测得好」的七条标准：各维度冠军

| # | 标准 | 为什么重要 | 冠军（依据） |
|---|---|---|---|
| 1 | 分数可重复（信度公开且有系数） | 没有信度的分数不能用于分档 | **IELTS 0.97 / SEM 0.17**；PTE 0.93；Versant 0.96 |
| 2 | CEFR 对接有外部验证 | CEFR 是家校公共语言 | **DET**（ACS Ventures + CIOL + 3,586 人）；EnglishScore（CRELLA） |
| 3 | 分辨率匹配用途 | 分班要区分度，申请只要阈值 | **DET（5 分步长）、iTEP（0.5 步长）**；TOEFL 2026 分段最不适合精细分班 |
| 4 | 口语有机器–人工一致性证据 | AI 最容易翻车的一环 | **Versant**（机器–人工 0.96；说 0.88）；DET Interactive Speaking >0.90 ⚠️ |
| 5 | 反作弊与异常分复核是流程 | 低龄/远程最常见代考背题 | **IELTS**（锯齿分自动重评）；iTEP 2026（照片+二维码+监考记录）；Linguaskill（2025-04 AI 远程监考） |
| 6 | 报告非专家能读懂 | 最后一公里是可用性 | **WIDA**（置信带印在成绩单）；DET（4 单项+4 整合分项算术定义）；TOEFL Primary（星级/徽章） |
| 7 | 成本与可得性 | 要规模化 | **EnglishScore US$14/人次**；EF SET 免费；CEPT 30 分钟即时出分 |

**没有系统七条全拿满**：DET 强在 1/2/3/6，弱在低龄；IELTS 强在 1/5，弱在分辨率与成本；K-12 工具强在 6/7，但 CEFR 系统性缺位。

## 4. 口语自动评分：全球怎么做的、哪家最硬

| 方案 | 能力 | 价格 | 证据 |
|---|---|---|---|
| **Pearson Versant** | 脚本化听说，15 分钟级 | 按量授权（未公开） | 分半信度 0.96 = 人工 0.96；机器–人工 0.96（说 0.88）✅ |
| **Azure Pronunciation Assessment** | 准确度/流利度/完整度/韵律；音素级 + 同音候选 | 按 STT 计价 | 官方公式：`0.4×最低 + 0.2×次低 + 0.2×第三 + 0.2×最高`（短板优先）；**使用区别于通用 STT 的专用模型** ✅ |
| **讯飞 ISE / E听说** | 音素级、11 类异常检测；**已用于全国中高考正式评分** | 商务询价 | 38000 校 / 2846 万用户 / **年评测 67 亿次**（厂商 2026-09）✅ |
| **Amira** | 儿童朗读流利度，4 分钟/人 | **$8/$20 每学生每年** | NCII 档案；输出 IRT + Lexile + 百分位 |
| **ELSA / SpeechAce** | 五维 + CEFR + 雅思/托福/PTE 映射 | 未公开 | 官方 API 文档 ✅ |
| **DET Interactive Speaking** | 题目随回答实时改，官方称首个自适应产出任务 | 含在 DET | 内部一致性 >0.90（⚠️ 厂商口径） |

**一条硬结论**：**通用 ASR 会抹平发音错误**——微软官方明确"发音评估使用与标准 STT 不同的专用模型"，ELSA 官方也警告"初学者口音会导致转写错误"。拿"转写文本 + 文本规则"当口语分，原理上不成立；我们的实现已把该项命名为表达分/待评测，方向正确。

## 5. 对中国 6–18 岁产品的净结论：三层组合

| 层 | 做什么 | 买还是自研 | 成本量级 |
|---|---|---|---|
| ① 国际锚（给家长看） | 每年 1 次 TOEFL Primary/Junior 或剑桥 YLE/A2 Key | **买**（第三方证书） | 数百元/人次（未核实报价） |
| ② 入学分班 | CEFR 级 + 单项 + 置信区间；对标 DET 分数结构与 CEPT 的 30 分钟形态 | **自研**（我们的题库+算法） | 固定研发 |
| ③ 口语发音评分 | 音素级准确度/流利度/完整度 | **买引擎**：讯飞 ISE（境内合规）> Azure PA > SpeechAce > ELSA | US$0.01–0.10/次量级（需询价） |
| ④ 低龄"好玩 + 可测量" | 6–8 岁游戏化测评 | **自研**（全行业空白） | 固定研发 |
| ⑤ 测评→教学处方 | 报告直接给"明天 25 分钟教什么" | **自研**（DET/IELTS 出分即止） | 固定研发 |

**预算红线建议**：入学测评一次性 ≤ ¥1/人、日常练习 ≤ ¥0.3/次、单学生月度 ≤ ¥10，否则撑不住 ¥399–699/年定价。

## 6. 可以直接抄的 8 个机制（零成本）

1. **DET 的分数结构**：4 单项 + 4 整合分项，整合分 = 两单项均值（算术定义公开）。
2. **DET 的 CEFR 披露格式**："级 → 分数段 → 证据来源与验证方"三列式。
3. **IELTS 的异常分复核**：口语与读写分差 >1 档时自动标记人工复核（锯齿分机制）。
4. **WIDA 的置信带**：报告给区间而非单一分，低龄家长更接受。
5. **MAP 的增长量表**：固定短测 + 纵向量表 + 每 4–6 周复测。
6. **DET Interactive Speaking**：预写剧本 + 实时选下一问 + AI 按 rubric 评（避免开放式 LLM 跑偏）。
7. **iTEP 2026 的核验套件**：照片 + 二维码 + 监考记录。
8. **MST（TOEFL 2026 路线）**：先做多阶段自适应，再谈逐题 CAT——CAT 需要 200–400 人/题的参数校准。

## 7. 必须承认的边界（诚实清单）

1. **价格是最大缺口**：TOEFL/IELTS/PTE 中国区官方价、K-12 商业工具（MAP/Star/i-Ready/FastBridge/WIDA）单价、各家 API 单价**全部不公开**，只能走询价单。
2. **Oxford Test of English 证据最弱**：关键字段均为二手，**不建议据此采购**。
3. **版本时效陷阱（2026 必须知道）**：TOEFL iBT 已从 0–120 改为 **1–6 分段**；Linguaskill 新版**只覆盖 B1–C2**；HMH Reading Inventory **已停售**。
4. **"考试分数可采信"≠"能预测学业成功"**：有报道显示用在线英语测试入学的学生在课程中更吃力；入学分档的最终效标应是"在我们课程里的进步速度"。
5. **K-12 的"好"标准不是 CEFR**：是筛查准确率（ROC 敏感度/特异度）与成长追踪；用 CEFR 要求 K-12 工具是错配。

## 9. 决策记录（2026-11-10）

**产品决策：自适应采用「MST（多阶段自适应）+ 基准/进度监测」，不先做逐题 CAT。**
- 依据：TOEFL iBT 2026 已改用 MST（见 06a [E04]）；MST 精度接近 CAT 但题库校准与曝光控制成本低得多；基准监测抄 WIDA/MAP/DIBELS 路线（置信带 + 纵向量表 + 定期复测）。
- 已落地原型：`public/english-assessment.html`（Router 12 → Stage1 14 → Stage2 14 → 产出 9；快速基准测 12 题 + 成长曲线）。
- 规格与题库扩容账：`docs/OPS_自适应测评架构_MST与进度监测_v1.md`（标准 MST 需约 105 题/档、4 档共 420 题；当前 49 题/档，P0 用贪心模块过渡）。
