# OPS 未来内容通道规划（v1，2026-11-11）

> 背景：David 现阶段采用"**纸质教材 + OPS 系统（测评 / AI 老师 / 练习 / 反馈）**"。
> 未来 OPS 体系化后，需要一个"内容通道"，让内容以其他形式进来并合规分发。本文只做方向与阶段规划，不承诺具体商务条款。

## 1. 现在（David 单人）

| 项 | 形式 |
|---|---|
| 主教材 | **纸质正版**（Oxford Discover 2 学生书 + 练习册） |
| 音频 | 教材官方音频 / 官方 App（晨听、泛听） |
| 练习与测评 | 917 站点（自编题库 + 测评 + AI 老师） |
| 教材映射 | 1 教材 Unit ↔ 本站 1 章（5 小节）；家长在主页勾进度 |
| 内容边界 | 我们只存"单元主题/词汇/语法点"大纲，不存教材原文/音频 |

## 2. 未来内容通道（按优先级）

### 通道 A：官方数字授权（首选）
- 与出版社（OUP / Cambridge / NGL 等）谈**数字内容授权**或**机构许可**：
  - 学生书电子版 + 音频在 OPS 内合法调用（账号绑定）；
  - 或使用出版社现有平台（Oxford Learner's Bookshelf、Cambridge GO）做单点登录/跳转。
- 优点：合规、内容权威；缺点：授权成本与谈判周期。

### 通道 B：教材"大纲"合作 + 自建内容
- 用教材的单元主题/词汇/语法（事实性信息）做骨架，OPS 自建练习与音频（TTS）。
- 优点：成本低、可控；缺点：仍需确认"大纲使用"的许可范围，不能替代教材体验。

### 通道 C：自研/合作出版内容
- OPS 自建分级读物与练习（公有领域 / CC BY-SA / 原创），形成自有 IP。
- 适合长期：可授权给学校/机构，形成内容资产。

### 通道 D：开放教育资源（OER）与公共语料
- 使用 CC BY / CC BY-SA / 公有领域材料（如 Simple English Wikipedia、Aesop），标注来源。
- 优点：零授权成本；缺点：分级与教学法需要二创。

### 通道 E：学校/机构采购
- 以"测评 + 教案 + 教师端"打包给学校，教材由学校统一采购（纸质或数字）。
- OPS 不转售教材，只提供系统与教研服务。

## 3. 需要的系统能力（对应通道）

| 能力 | 说明 | 状态 |
|---|---|---|
| 教材大纲数据模型 | Unit/Chapter/Lesson、词汇表、语法点、蓝思/CEFR 标签 | ✅ 已有 curriculum/textbooks 雏形 |
| 内容权限与租户 | 学校/家庭账号、内容可见范围 | ⬜ 未做 |
| 官方内容接入 | 电子书/音频授权接入或跳转 | ⬜ 未做 |
| 内容版本管理 | 教材版本、单元映射版本 | ⬜ 未做 |
| 学习数据合规 | 儿童数据最小化、家长同意 | ⬜ 待设计 |

## 4. 阶段路线（建议）

1. **P0（现在）**：David 纸质教材 + OPS 系统；把"教材 Unit ↔ 章节"映射跑顺，验证教学效果。
2. **P1（1–2 个月）**：沉淀"教材大纲库"（多套教材的 Unit/词汇/语法映射），支持家长自选教材。
3. **P2（3–6 个月）**：接触出版社，试点官方数字授权或平台跳转；同时扩充自有 OER/原创内容。
4. **P3（6–12 个月）**：面向学校/机构的"测评+教案+教师端"打包，教材由机构采购；OPS 提供内容通道与数据接口。

## 5. 红线（不变）
- 不扫描/不传播教材 PDF、音频、练习册页面；
- 不把"教材内容"包装成自有内容售卖；
- 儿童数据最小化，家长可导出/删除。
