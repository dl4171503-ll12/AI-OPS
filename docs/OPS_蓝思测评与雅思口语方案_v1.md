## 0. 一句话

**先用 MST 自适应把学生的阅读水平定位到蓝思区间（如 600L–780L），再按这个区间从雅思口语题库里挑对应难度的题**——阅读决定"能读什么"，口语决定"能说什么"，两边共用一把尺。

## 1. 蓝思年级区间（有出处的基准）

> 来源：MetaMetrics 2010–2019 研究（300 万+ 美国学生），25th–90th 百分位；转引自 RIT Libraries 指南（2026-06 更新）。
> 表格是"同年级典型读者的范围"，**不是**某个学生的测量值。

| 年级 | Lexile 区间（25th–90th） | 我们产品里的用途 |
|---|---|---|
| G1 | BR35L–570L | 初级（A1）起始区间 |
| G2 | 245L–795L | 初级到中级 |
| G3 | 480L–985L | 中级 |
| G4 | 700L–1160L | 中级到雅思预备 |
| G5 | 795L–1260L | 雅思预备 |
| G6 | 875L–1340L | 雅思预备到高级 |
| G7 | 940L–1410L | 高级 |
| G8 | 1000L–1470L | 高级 |
| G9 | 1050L–1520L | 高级上限 |
| G10–12 | 1095L–1610L | 超出我们 6–18 岁主力区间，仅参考 |

**使用规则**：推荐阅读材料 = 学生蓝思值 **+50L ~ −100L**（业界通行做法，来自同一来源）。

## 2. 阶段一：蓝思阅读阶梯（已取消 MST）

> 2026-11-10 晚产品决定：**取消 MST（Router/Stage 模块）**，改用蓝思测评本身的"阶梯"做法。

### 2.1 阶梯规则
1. 题库：8 篇阅读材料（各档 2 篇，每篇 4 题），按估计蓝思值升序排列：300 / 450 / 600 / 750 / 780 / 1050 / 1200 / 1350。
2. 起点：按学生所选水平的基准蓝思值，选**最接近的一篇**（初级 300L / 中级 600L / 雅思预备 900L / 高级 1200L）。
3. 每轮：读一篇 + 答 4 题，**整段提交后**按正确率决定下一篇：
   - 正确率 **≥75%** → 蓝思 +150L（找上限）
   - 正确率 **≤50%** → 蓝思 −150L（保底）
   - 中间 → 蓝思 +75L（继续探顶）
4. 共 **5 篇（20 题）** 结束（基准测为 3 篇 / 12 题）。
5. 蓝思估计：每篇给候选值 `篇蓝思 + (正确率−0.75)×200`，取 5 篇候选的均值；夹在 **BR–1600L**，输出取整到 10L。
6. 不可跳题、不可改已提交段落（阶梯路径依赖作答结果）；**提交前可在本段内改答案**。

### 2.2 题目蓝思标签（估算）
每篇按"档位基准 + 难度偏移"给估计值：初级 300L / 中级 600L / 雅思预备 900L / 高级 1200L，再按 tier 偏移 −120 / 0 / +150。

**说明**：这是工程估算，不是官方 Lexile Analyzer 结果（见 §6）。

## 3. 阶段二：雅思口语（难度随蓝思）

### 3.1 题目选择规则
按阶段一测出的 Lexile 区间落档，选对应的雅思口语任务组合：

| 蓝思区间 | 雅思口语配置 | 难度说明 |
|---|---|---|
| **< 400L** | Part 1 × 3（姓名/年龄/颜色/家庭）＋ Part 2 简版（描述家人/房间，30–40 秒） | 只用熟悉、具体、当下的话题 |
| **400–700L** | Part 1 × 3 ＋ Part 2（描述喜欢的食物/一天，40–60 秒）＋ Part 3 × 1（简单追问：为什么） | 具体话题 + 一个"为什么" |
| **700–1000L** | Part 1 × 3 ＋ Part 2 标准题卡（1–2 分钟）＋ Part 3 × 2（比较/原因） | 标准雅思结构 |
| **1000–1300L** | Part 1 × 2 ＋ Part 2 标准题卡 ＋ Part 3 × 2（观点/评价） | 抽象度上升 |
| **> 1300L** | Part 1 × 1 ＋ Part 2 标准题卡 ＋ Part 3 × 3（评价/推测/让步） | 接近雅思 6.5–7 的讨论深度 |

### 3.2 评分（雅思四维，0–9 band）
| 维度 | 依据 | 当前实现 |
|---|---|---|
| Fluency & Coherence (FC) | 长度、衔接词、句子数 | 文本规则 **预估** |
| Lexical Resource (LR) | 词汇多样性、学术/低频词比例、话题词命中 | 文本规则 **预估** |
| Grammatical Range & Accuracy (GRA) | 复杂句使用、明显语法错误检测 | 文本规则 **预估** |
| Pronunciation (P) | 音素级发音 | **Azure Pronunciation Assessment**（已接代理，需配密钥；未配置标"待评测"） |

- 总分 = 四维平均，**以 0.5 band 为步长**；P 缺失时不冒充，只给三维平均并标注。
- **诚实口径**：文本规则得到的 FC/LR/GRA 是"预估值"，不是考官评分；对外必须写"AI 预估，仅供参考"。

## 5. 基准/进度监测（沿用 4 周节奏）
- 基准测 24 题（阅读/词汇/语法/听力），输出**蓝思区间**，每 4 周一次。
- 成长曲线纵轴改为**蓝思档**（如 <400L / 400–700L / 700–1000L / 1000–1300L / >1300L）。
- 家长版只看"蓝思区间 + 趋势"，量尺分/θ/SE 内部用。

## 6. 诚实边界（必须写进对外文档）
1. **我们做的不是官方 Lexile 测量**：Lexile 是 MetaMetrics 的注册商标与专利量表，正式测量需授权测评或官方工具。我们的数值是"基于题目难度估计的参考区间"，**不得对外称"蓝思值"为官方结果**。
2. 题目 Lexile 标签是**估算**（档位基准 + 难度偏移），不是文本分析器算出的真实 Lexile；上线前应用官方 Lexile Analyzer 校对 20–30 篇语料。
3. IELTS 口语的 FC/LR/GRA 是**文本规则预估**，与真实考官评分有差距；P 依赖 Azure，未配置时不给分。
4. 需要校准：50–60 名学生同时做我们的测评与官方 Lexile/雅思口语，算相关与分档一致率（目标：蓝思相关 ≥0.80，口语 band 差 ≤0.5 的比例 ≥70%）。

## 8. 防蒙、去重与内容扩容（v2.2，2026-11-10）

### 8.1 修复"点第一个就能蒙对"
**根因**：题库生成时正确选项集中在第 1 位（实测初级 76%、中级 90%、雅思预备/高级 71%）。
**修复（三层）**：
1. **静态配平**：`scripts/rebalance-options.mjs` 轮转选项，使 1/2/3 位各约 1/3（实测每档 14/14/13）。
2. **运行时打乱**：页面按会话种子（`examSeed + 文章id + 题号`）对每题选项做确定性 shuffle，同会话稳定、跨会话不同；答案仍按文本比对。
3. **校验器硬规则**：主库 `validate-items.mjs` 答案位置占比 >50% 直接报错；扩展阅读 `validate-extra-reading.mjs` >45% 报错。

### 8.2 修复"同一次测评重复用同一篇"
**根因**：阶梯只排除了"上一篇"，没有排除"本次已用过的文章"。
**修复**：`Exam.used` 集合记录已用 id，`pickPassage()` 只从未用池里取最近难度；池空提前结束。

### 8.3 内容扩容：8 篇 → 32 篇
| 来源 | 篇数 | Lexile |
|---|---|---|
| 原题库（各档 2 篇） | 8 | 300 / 450 / 600 / 750 / 780 / 1050 / 1200 / 1350 |
| `reading-extra-low.json` | 12 | 200 / 230 / 250 / 300 / 350 / 400 / 450 / 500 / 550 / 600 / 650 / 700 |
| `reading-extra-high.json` | 12 | 750 / 750 / 850 / 950 / 950 / 1050 / 1150 / 1150 / 1250 / 1350 / 1350 / 1450 |
| **合计** | **32** | **200–1450，14 个百位档** |

- 每篇 4 题（细节/推断/词义/主旨或态度），答案位置两批均 16/16/16。
- 语料：Aesop 寓言/传统童话（公有领域）与 Wikipedia/Simple English Wikipedia（CC BY-SA）改写，`source` 标注出处，未编造 URL、未整段照抄。
- 校验：`scripts/validate-extra-reading.mjs`（篇数、4 题、3 选项、答案合法、lex 区间、位置均衡、<700L 必填中文）。

### 8.4 低龄段辅助（v2.3 修正：不再给中文情节提示）
- **初级/中级**：只显示 **emoji 插画**（示意故事元素，不剧透）+ **每题的"中文题意"**（仅翻译问法，不提供情节）。
- **已删除"中文情节提示/摘要"**：原摘要等于把整个故事讲完，会破坏阅读理解测评效度。题库里的 `zh.summary` 字段保留（供老师/内部教研用），但**页面不再渲染**。
- **最后一篇（最难）去掉插画与中文题意**；雅思预备/高级不显示任何中文。
- 当前插画为 emoji 示意，后续可替换为正式插图。

`node scripts/e2e-lexile-assessment.mjs` 全过，新增断言：题库 ≥30 篇（实测 32）、蓝思覆盖 ≥10 个百位档（实测 14）、5 篇不重复、首选项正确数 ≤3/4（实测 0）、pct 不全 ≥75%（防蒙）、低龄中文/插画、最后一篇去中文、报告图表齐全、基准蓝思曲线、异常锁死、无 JS 异常。
