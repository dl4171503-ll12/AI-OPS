# David 每日英语学习方案：1 小时精学 + 碎片时间（v1，2026-11-11）

> 前提：David 小学三–四年级，级别以**测评报告 Lx**为准（不用人教版年级）；当前按 **L2 / A2** 设计，可整体升降。
> 每天英语总投入：**60 分钟精学（专注）** + 碎片时间约 **30–45 分钟**（不计入 60 分钟）。

---

## 0. 先对齐一个冲突（重要）

你之前定的"每天至少 1 个单元（5 章 × 5 节 = 25 小节）"，按每节 5 分钟算是 125 分钟，**和现在 1 小时精学冲突**。

**建议方案（本方案采用）**：
- 每节压缩为 **2–3 分钟**（6 道小题）→ 1 个单元 25 节约 **50 分钟**
- 加上 10 分钟"复盘+听写+口语" → **正好 60 分钟**
- **每天 1 个单元 = 硬性打卡**；"3 个单元"只放在**周末/假期**（3 小时），平时不要求

若你希望平时也 3 个单元，那每天英语总时间需约 3 小时，需要你确认。

## 1. 每日时间表（上学日，模板）

| 时段 | 时长 | 做什么 | 形式 |
|---|---|---|---|
| **起床后** | 10 分钟 | 听"当天难度"的新闻/故事音频（L2：VOA Learning English 慢速、BBC Learning English 简短新闻） | 只听听、不跟读；洗脸/穿衣时播放 |
| **上学路上** | 10–15 分钟 | **泛听**：把早上音频再听 1 遍 + 昨天听过的一段 | 不看屏幕；能听懂 60% 即可 |
| **放学后（精学 60 分钟）** | 0–5 | 热身：昨日错题 3 句听写 | 917 首页 → 复习 |
| | 5–35 | **主教材单元课**：Oxford Discover 2 一个 Unit + 917 章节 2–3 节（词汇/语法/听力/阅读） | 917 上课页 |
| | 35–45 | 口语：跟读 + 录音 2–3 句（老师听） | 917 口语小节 |
| | 45–55 | 写作/语法小练：3–5 句或 40 词 | 917 写作小节 |
| | 55–60 | 今日听写 2 句 + 单元小测 | 917 |
| **晚饭后碎片** | 5–10 分钟 | 小口语：AI 问 2–3 个问题，孩子口头回答（可录音） | 917 或手机 |
| **睡前** | 10 分钟 | 轻复习：今天错的词/句看图/听音 1 遍 + 朗读 1 小段 | 917 卡片/教材音频 |

> 弹性：孩子累的日子，精学压到 40 分钟（做 2 章）+ 碎片照常；不要断连胜（至少 1 单元可拆到第二天早上补）。

## 2. 60 分钟精学怎么切（4 个模块）

| 模块 | 分钟 | 内容 | 产出 |
|---|---|---|---|
| A 热身与复习 | 5 | 昨日错题、间隔复习卡 | 正确率 |
| B 主教材新课 | 30 | Oxford Discover 2 单元 + 917 对应章节 | 2–3 节完成 |
| C 输出（口语/写作） | 20 | 跟读录音、3–5 句写作 | 录音/短文 |
| D 听写与测评 | 5 | 2 句听写 + 小测 | 分数 + 老师评估 |

**和 917 的对应**：B→上课页（lesson），C→口语/写作小节，D→听写小节；每天结束自动回传表现（`/api/school-progress`），老师给出"太难/刚好/太简单"与调整。

## 3. 碎片时间任务库（按优先级轮换）

| 场景 | 时长 | 任务 | 频率 |
|---|---|---|---|
| 起床 | 10 分钟 | 听**当前 Unit 的教材音频**或同级别分级读物音频（故事优先） | 每天 |
| 路上 | 10–15 分钟 | 泛听：**同一段音频再听一遍**（能懂 60–70% 即可，不查词、不暂停） | 每天 |
| 晚饭后 | 5–10 分钟 | 口语小问答（AI 提问，孩子口头回答） | 隔天 |
| 睡前 | 10 分钟 | 同一段音频再听 1 遍 + 今天错词/错句听音 | 每天 |
| 其他碎片 | 3–5 分钟 | 阅读小测（1 篇短文 2 题）、单词卡 | 随机，每天 1–2 次 |

### 3.1 碎片听力的选材规则（关键）

1. **跟着教材走**：优先用 **Oxford Discover 2 当前单元的配套音频**——孩子刚学过，词汇和句型熟，听起来不费劲。
2. **同难度分级读物**：Oxford Reading Tree 4–6 级音频（故事、语速慢、句子短）。
3. **难度标准**：**能听懂 60–70%** 最合适；<50% 就降一级（ORT 3），>85% 就升一级。
4. **同一段听 3 次**：起床听 → 路上泛听 → 睡前复习。重复比"每天换新材料"更有效。
5. **不用 VOA 时事新闻**：语速快、背景知识多，L2 会听不懂、容易挫败。

### 3.2 可用资源（按推荐顺序）

| 资源 | 适合度 | 说明 |
|---|---|---|
| **Oxford Discover 2 配套音频** | ★★★★★ | 与课程完全同步，最稳 |
| **Oxford Reading Tree 4–6 级音频** | ★★★★★ | 故事简单、语速慢，适合泛听 |
| **Little Fox 分级故事（Level 2–3）** | ★★★★ | 动画/音频分级清晰，孩子爱听 |
| **VOA Learning English — Let's Learn English Level 1** | ★★★ | 不是新闻，是慢速情景对话，比 VOA 新闻简单 |
| **ESL Fast / Breaking News English（Level 0–1）** | ★★★ | 分级短新闻/对话，可选简单档 |
| ~~VOA 常规时事新闻 / BBC 6 Minute English~~ | ✗ | 对 L2 偏难，暂不用 |

## 5. 数据与调整（闭环）

每天记录：
- 精学：完成小节数、正确率、口语录音、写作字数
- 碎片：听力时长（自报/勾选）、泛听材料、睡前复习是否完成
- 主观：孩子状态（开心/一般/抗拒）

每周日看板：
| 指标 | 目标 | 不达标动作 |
|---|---|---|
| 精学完成天数 | ≥5 天 | 减少单次时长、拆成 2 段 |
| 单元完成 | ≥5 个/周 | 若 <3 → 降教材级别或拆单元 |
| 正确率 | 50–89% | <50% 降难度；≥90% 升难度 |
| 碎片听力 | ≥30 分钟/天 | 换更简单材料 / 固定场景 |

调整规则与 917 的 `/api/school-progress` 一致：太难→降 100L/降级；太简单→加挑战；波动→加复习课。
