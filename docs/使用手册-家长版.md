# AI一人学校 · 使用手册（家长版）

## 进入家长中心
校园右上角「家长中心」→ 输入 PIN（默认 `1234`，请尽快在设置中修改）。

## 可查看内容
- 各科学情得分条 / 练习与错题概况
- 错题本速览
- 心理情绪摘要（不含完整谈心原文）
- 社交风险事件与拦截记录
- 成就徽章与校园装饰兑换（用孩子积分）

## 安全控制
- 可关闭「允许校际社交」
- 可选择低龄聊天「全部可见」或「仅风险摘要」
- 中度/重度违规消息会被拦截并出现在风险列表

## 鼓励孩子
在家长中心写下鼓励语并发送，孩子可在「设置」页看到弹窗消息。

## 隐私说明
1.0 数据保存在本机浏览器。换设备需重新入学或自行备份。正式上线版将迁移至服务端加密存储。
