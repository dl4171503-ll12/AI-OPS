# 现有内容属于哪套教材体系？——诚实盘点与选材建议（v1，2026-11-11）

## 1. 一句话结论

**现在的课程内容是我们自编的题库，不是任何一套出版社教材的原文或单元。** 它"对标"了剑桥考试阶梯、CEFR、蓝思与雅思四维，但**没有采用某一本教材的单元编排、词汇表、语法顺序和配套音频**。

## 2. 逐项盘点（哪些是自编 / 哪些有出处）

| 内容 | 来源 | 说明 |
|---|---|---|
| 917 课程结构（5 单元 × 5 章 × 5 节） | **自编** | 章节名（认识与问候/家庭与朋友/…）是我们设计的主题轴，不是某教材的目录 |
| 每节 6 道题（词汇/语法/听力/阅读/听写/口语/写作） | **自编题库** | 来自 `public/items/*.json`（AI 编写，每级 49 题）+ 扩展阅读 24 篇 |
| 阅读文章 | **改编** | 伊索寓言/格林/安徒生（公有领域）+ Simple English Wikipedia（CC BY-SA，标注 `source`）；题目是我们出的 |
| 听力/听写/口语/写作题 | **自编** | 按雅思/CEFR 题型风格原创，不是真题，也不是教材练习 |
| 蓝思级别、L1–L5、雅思四项目标 | **标准对标** | MetaMetrics 年级区间（转引 RIT）、雅思 band 描述、CEFR 对照；映射是我们做的 |
| 图片 | AI 生成（MiniMax） | 不是教材插图 |

**所以**：可以理解为"**按剑桥/雅思/蓝思的模式自编的一套课程**"，而不是"Oxford Discover / Think / Kid's Box 的某一册"。

## 3. 这套自编内容的问题（为什么建议换系统教材）

1. **没有出版社的"范围与顺序"（scope & sequence）**：词汇、语法点是按考试题型临时覆盖，不保证螺旋上升、不保证与某一级别完整对应。
2. **评估导向 > 教学导向**：题库为测评设计（每题独立、追求区分度），缺少教材的"输入—操练—输出—复习"单元闭环。
3. **缺少配套音频/练习册/教师用书**：真实课堂和家庭自学都依赖这些支架。
4. **文本难度靠估算**：蓝思标签是估算，不是官方 Analyzer；长篇输入量也远少于教材。
5. **主题不成体系**：章节主题是"拼接式"，不是教材那种跨单元复现与项目式任务。

## 4. 建议：选一套"主教材"做骨架，我们的系统做"测评 + 练习 + 反馈闭环"

### 4.1 三条路线（按目标选一条）

| 路线 | 主教材 | 适合 | 优点 | 代价 |
|---|---|---|---|---|
| **A. 少儿综合线（推荐给 1–4 年级）** | **Oxford Discover 1–2**（OUP，探究式 Big Questions，四技能） | 小学低中年级、想打综合基础 | 主题式、四技能均衡、配套音频/视频/练习册 | 需要买书/账号；进度比考试线慢 |
| **B. 剑桥考试线（推荐给 5–6 年级/初一）** | **Kid's Box / Power Up（Starters–Flyers）→ Prepare 3–4（KET/PET）** | 有 KET/PET 目标 | 与剑桥考试一一对应，备考效率高 | 应试味重，低龄可能枯燥 |
| **C. 青少年思辨线（推荐给初一以上）** | **Think 1–3**（剑桥，critical thinking）→ Think 4–5 / Prepare 5–6 → IELTS | 初高中、目标雅思 | 思辨+学术写作，衔接雅思 | 对基础要求高，需老师带 |

补充：分级读物（Oxford Reading Tree / RAZ / 国家地理 Readers）按蓝思区间选，作为"每天 15 分钟阅读"的输入量。

## 5. 落地方式（不侵权）

- **教材做"大纲"**：单元主题、词汇表、语法点属于事实性信息，可用来建课程骨架。
- **课文/音频/练习**：不复制；我们用自编题目 + 合法语料（公有领域/CC BY-SA）配套。
- 每单元映射：教材 Unit → 我们的 Chapter → 5 节（词汇/语法/听/读/说/写轮换），测评点对齐该单元目标。
