# OPS 学习数据规范 v1

- 主身份：学生 ID；本地缓存按手机或邮箱分别隔离。新增邮箱槽不自动吸收来源不明的 guest 档案。
- 学习记录：题目、作答、推理、用时、改答快照、知识点、单元、对错、提示、待验证归因、时间、掌握度。
- 归因必须区分事实与推测；无推理证据时不得声称已找到根因。
- 项目证据：项目 ID、事件 ID、时间、类型、正文；会议另存六问快照。
- 项目资金：整数分，收入/支出与成本分类；不与 XP 混用。
- XP：唯一余额为 student.points；累计为 ops.xpTotal；分科按奖励事件计算，不做跨学科综合能力分。
- 本地档案：.ops-data/学生ID/YYYY-MM-DD/类型.ops.enc.json。密文中同时包含 learning.json 与 report.md。
- 密文不保存密码、家长 PIN、联系方式或社交私信。浏览器已有明文缓存不是加密档案，不适用于共享电脑的强隔离要求。
- 每次启用归档立即导出，保持打开期间每日检查；周日归档，月末快照。关闭页面后的调度另行实现。
- 完整学科历史与项目答案默认不发送到外部 AI；只有家长主动启用数据使用后才发送到现有 AI 服务。
- 本地题库与规则引导可在外部 AI 不可用时继续使用，但首次加载站点仍需要本地 Vite 服务。

解密：在项目终端运行 `node scripts/ops-decrypt.mjs "密文完整路径" "解密输出目录"`，随后输入归档口令。输出包含明文，应存放在受保护的个人目录；不会覆盖已有同名文件。
