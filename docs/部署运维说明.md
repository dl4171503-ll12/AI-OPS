# AI一人学校 · 1.0 部署与运维说明

## 环境
- Node.js 18+
- 系统：Windows / macOS / Linux

## 配置密钥
复制 `.env.example` 为 `.env`，填入从彩光AI迁移的密钥：

```
DEEPSEEK_API_KEY=sk-...
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_API_KEY_BACKUP=...   # Kimi/Moonshot 备用（可选）
VITE_DEEPSEEK_API_KEY=...     # 仅本地兜底（可选）
```

开发服务器通过 Vite 插件 `POST /api/school-llm` 调用 DeepSeek（失败则尝试 Kimi）。

## 启动
```bash
cd ai-school
npm install
npm run dev
```
浏览器打开：http://127.0.0.1:919/

## 构建
```bash
npm run build
npm run preview
```
预览：http://127.0.0.1:920/

## 数据存储
1.0 学生数据、错题、社交、情绪摘要使用浏览器 `localStorage`（zustand persist）。
清浏览器站点数据即重置；设置页也可「重置学校」。

## 分支
本项目在独立 Git 分支 `ai-one-person-school` 开发。

## 安全注意
- 不要把含真实密钥的 `.env` 提交到公开仓库
- 儿童社交内容经本地审核模块拦截 PII / 辱骂 / 不当内容
- 家长中心默认 PIN：`1234`，请家长登录后修改
