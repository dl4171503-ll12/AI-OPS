# 多邻国玩法 × 英语测评/学习（v1，2026-11-11）

> 目标：把"测评"从一次性考试变成"测评 + 每日学习"的循环，用多邻国的机制驱动孩子每天回来练。

## 1. 多邻国核心机制拆解 → 我们的映射

| 多邻国机制 | 作用 | 我们的落地 |
|---|---|---|
| **XP（经验值）** | 每答对给分，形成"今天有收获"的反馈 | 答对 +10 XP；听写按命中率给分；完美段落 +20 XP |
| **连击 Combo** | 连续答对时倍率提升，制造爽感 | 3 连击 ×1.2、5 连击 ×1.5，答错清零 |
| **❤️ 生命值** | 提高紧张感与"认真答"的动机 | 学习模式 5 颗心；答错 -1；测评模式不扣（保证测评数据完整） |
| **🔥 连续天数 Streak** | 最强留存机制 | 当天完成 ≥30 XP 记 1 天；断签清零并显示"别断签" |
| **每日目标** | 把大目标拆成今天的小目标 | 每日 30 XP；顶部进度环"今日 20/30 XP" |
| **段位/排行榜 League** | 周维度竞争 | 青铜/白银/黄金（按本周 XP 本地计算），不涉及真实社交 |
| **学习路径 Path** | 把内容组织成"关卡地图" | 4 个单元（初级/中级/雅思预备/高级）× 3 课；前一课完成后解锁下一课 |
| **小课 Lesson** | 5 分钟、短平快、必完成 | 每课 8 题：词汇/语法/听力/阅读/听写混排；结束给 XP 与正确率 |
| **即时反馈** | 答对/答错立刻给颜色+鼓励 | 绿/红反馈条 + 🦉 鼓励语；答错显示正确答案 |
| **错题复习 / 间隔重复** | 让"错过的"再出现 | SRS：答对 box+1（间隔 1/2/4/7/15 天），答错归零；下一课优先出"到期题" |
| **成就徽章** | 长期目标 | 首个完美课、7 天连胜、100/1000 XP、完成一个单元 |
| **单元小测 / 测评** | 检验学习效果 | 我们的蓝思阶梯 + 听说读写测评 = "单元小测"，报告给雅思/朗思口径 |

## 2. 测评端的改造（本次已实现）
1. 顶部常驻 **游戏条**：🔥 连胜天数 · ⚡ 今日/总 XP · 每日目标进度 · ❤️（学习模式）。
2. 每完成一段（阅读/听力/听写/口语/写作）**即时给 XP + 鼓励反馈**，不是"交卷才看到分"。
3. 报告页顶部显示"本次获得 XP / 今日目标 / 连胜"，并提供 **"开始今日学习"** 按钮。
4. 报告仍然保留雅思/朗思的严肃口径——游戏化只负责"愿意学"，分数不注水。

## 3. 学习端（本次已实现）
**学习路径**：4 单元 × 3 课，按测评水平从对应单元开始；上一课完成解锁下一课。  
**每课 8 题**：词汇/语法/听力/阅读/听写混排；听力用真人 TTS 美音；  
**课堂机制**：5 颗心、连击倍率、即时对错反馈、答错展示正确答案；  
**结束结算**：正确率、获得 XP、❤️ 剩余、连胜；触发成就；  
**间隔复习**：每道题记录 box 与到期日，下一课优先出到期题。

## 5. 不做/边界
- 不做真实排行榜与社交（儿童隐私）；段位只在本机呈现。
- 不卖"补心/连胜冻结"——这是儿童教育产品，避免诱导付费。
- 学习模式的心只影响单课结算，不影响测评数据；测评永不被中断。
- 所有分数口径仍以雅思/朗思为准；XP 不是能力值，不能对外当成绩。
