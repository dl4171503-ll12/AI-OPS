# AI 老师课堂设计（v1，2026-11-11）

> 目标：一个"看过 David 测评报告、知道他水平"的 AI 老师，在课堂里能讲解、能互动、能出题测评、能形成反馈。

## 1. 老师人设（已写进接口）

- 对象：8–10 岁中国孩子，英语 L2 左右（以测评报告为准）
- **授课语言：英文为主（约 90%）**，句子短、符合他的级别；只有明显卡住时给一句极短中文提示
- **输出优先**：每一轮都必须让孩子开口/动笔说英语；讲解只占很少
- **纠错闭环**：说错 → 老师用正确句子重述（recast）→ 让孩子**再说一遍** → 再进入下一题
- 规则：一次 2–4 句、一次只问一个问题；答对具体表扬；答错不批评；连续错降难度
- 禁止：长篇语法讲座、一次多个问题、任何技术/软件词汇

## 2. 老师"知道"什么（学生档案注入）

每次对话把以下信息带给老师：
- 年级、蓝思定级（Lx）、蓝思值
- 雅思四维（听/说/读/写）与 CEFR
- 最弱项（来自测评报告）
- 当前课程位置（单元/章节/小节）与本节练习
- 最近 8 条对话（保持上下文）

## 3. 一节 AI 课的结构（约 15–20 分钟）

**说话优先**：老师每句话自动朗读（英文），学生尽量用 🎤 说；**只有拼写/听写/语法练习/写作**才要求打字或写字。

| 环节 | 时长 | 老师做什么 | 学生做什么 |
|---|---|---|---|
| 开场 | 1 分钟 | 英文打招呼 + 今天目标 | 听 |
| 讲解 | 3–4 分钟 | 用他能懂的语言讲一个点 + 一句例句 | 听/跟读 |
| 互动操练 | 8–10 分钟 | 一题一问：先说，再让他说；听不懂就简化重说 | 说（🎤）/少量写 |
| 即时反馈 | 每题 | 对：具体表扬+推进；错：重述正确说法→让他再说一遍 | 重说 |
| 小测与总结 | 3–5 分钟 | 正确率 + 明天练什么 | 听 |
| 回传 | — | 写入学习记录与主 Agent 评估 | — |

**听不懂机制**：学生点「🤔 听不懂」→ 老师**不推进**，把同一问题说得更慢、更简单，给一个例子，再问一次；必要时才用一句极短中文。

## 4. 交互方式（分阶段）

| 阶段 | 形态 | 状态 |
|---|---|---|
| **P1（已实现）** | 英文授课 + **老师自动朗读** + 学生 🎤 语音回答（识别）+ 打字兜底；**听不懂**按钮触发简化重说；输出优先、纠错重说 | ✅ `/tutor.html` |
| P2 | 老师语音实时对话（说完即回，低延迟） | ⬜ 已有 TTS/ASR 接口，待做流式 |
| P3 | 数字人/头像 + 实时语音对话 | ⬜ 后续 |

## 5. 反馈闭环

- 每节课结束：正确率、错题、老师评语 → 写入 `ops917-tutor-session`，并 POST `/api/school-progress`
- 主 Agent 评估：太难/刚好/太简单 → 下一节难度、复习内容、教材单元调整
- 家长周报：完成课时、正确率、蓝思/雅思变化、下周安排

## 7. 边界与安全

1. **不是真人老师**：AI 讲解可能出错，关键内容以教材为准；家长/老师可复核。
2. **内容有据**：练习来自我们题库/教材大纲，不让模型自由编题。
3. **不采集隐私**：只传学习数据（级别、分数、错题），不传真实姓名/照片。
4. **不替代考试**：测评分数仍是参考，不宣称官方成绩。
5. **成本**：每节课约 6–10 次模型调用；需控制频率（每分钟 ≤ 若干次），失败自动降级为模板话术。

## 11. 课堂控制（2026-11-12 加入）

| 功能 | 说明 |
|---|---|
| **↩️ 撤回** | 撤回上一条回答（语音或文字），连同老师已回的那条一起删掉，文字放回输入框；可重新说/重新发；快捷键 Ctrl+Z |
| **老师语速** | 偏慢 0.75x / 正常 0.95x / 偏快 1.15x，立即生效并记住；用于不同听力难度练习 |
| **练习量** | 少一点（核心 8 项）/ 标准 / 多一点（含拓展题） |
| **Lesson 切换** | Unit 1 分 4 课，顶部 chip 切换，完成显示 ✓，课后给下一节 |
| **下一题传递** | 前端每轮把 `nextQuestion` 明确传给老师，老师回复=反馈+下一题，避免卡在同一题重复问 |

## 12. 学习记录、自适应与语音兜底（2026-11-12 加入）

### 12.1 自动留存 / 一键恢复
- 每次对话、答题、撤回都会把状态写入 `ops917-session:v1`（题目、进度、正确数、对话、薄弱词）
- 刷新/关页后再打开同一课，顶部出现「**继续上次课程**」/「重新开始」
- 恢复后对话记录、题号、正确数、撤回栈全部还原
- **恢复时历史消息全部静音，只朗读最新一条老师消息**（避免批量朗读旧消息）

### 12.2 自适应调整
- 每课结束记录到 `ops917-mastery:v1`：pct、薄弱词（错题答案）
- **pct < 50%**：练习量自动降为"少一点"，下次先复习错词
- **pct ≥ 90%**：练习量自动升为"多一点"，下一课按钮显示"加速"
- 有薄弱词时出现「**复习薄弱词**」入口：听写错词 → 造句 → 写作
- 课件仍可手动改"练习量/语速/Lesson"

### 12.3 语音额度兜底（MiniMax 402 insufficient balance）
- 老师朗读失败（402/网络）→ 自动切换**浏览器英文语音**（speechSynthesis），不中断上课
- 语音识别失败（402）→ 自动尝试**浏览器识别**（SpeechRecognition）；不可用则提示打字
- 页面不再显示原始 JSON 报错，只显示"语音服务额度不足，先用打字；家长充值后自动恢复"
- 充值 MiniMax 后原语音/识别自动恢复，无需改代码

## 13. 临时切换 Edge TTS（2026-11-12）

MiniMax 暂停期间，服务端 `/api/school-tts` 统一改走**免费 Edge TTS**（Python `edge-tts`），所有页面（课堂/测评/课程）无需改动：

| 配置（.env） | 作用 |
|---|---|
| `TTS_PROVIDER=edge` | 强制走 Edge，不调用 MiniMax |
| `MINIMAX_DISABLED=1` | ASR 直接返回 503（前端自动改用浏览器识别） |
| `EDGE_VOICE_EN=en-US-AriaNeural` | 英文语音（可选 en-US-JennyNeural / en-US-GuyNeural） |
| `PYTHON_BIN=...` | 指定 Python（含 edge-tts 包） |
| 缓存 | `node_modules/.cache/edge-tts/*.mp3`，重复句子直接命中（约 14ms） |

**恢复 MiniMax**：`.env` 改 `MINIMAX_DISABLED=0`、`TTS_PROVIDER=minimax`，重启 dev server；充值后原语音自动回来。

## 14. 本地离线语音识别（Vosk，2026-11-12）

浏览器识别（Chrome 的 Web Speech）依赖境外服务，实测不可用；改为**本机离线识别**：

| 项 | 说明 |
|---|---|
| 引擎 | Vosk `vosk-model-small-en-us-0.15`（约 40MB，离线、免费） |
| 模型位置 | `D:\Desktop\ai-school-models\vosk-model-small-en-us-0.15`（项目外，避免 Vite 监听） |
| 服务 | `python scripts/local_asr.py` → `http://127.0.0.1:8201/asr` |
| 代理 | `/api/school-asr` 在 `MINIMAX_DISABLED=1` 时转发本地服务；本地没启动才回退浏览器/打字 |
| 前端 | 录音仍是 WAV 16k，无需改；识别结果直接进输入框并发送 |

启动命令（后台常驻）：
```
powershell -ExecutionPolicy Bypass -File scripts\start-asr.ps1
```
（脚本会检测 8201 是否已在运行；未运行则以隐藏窗口启动，日志在 `D:\Desktop\ai-school-models\local_asr.log`）

**守护机制（2026-11-12 强化）**：918 dev server 启动时会自动拉起本地识别进程，并在它退出/被杀后 3–7 秒自动重启（`vite-plugins/school-asr.ts` 的 `ensureLocalAsr`）。所以 **918 在，识别就在**，不需要单独维护；918 不运行或模型缺失时课堂才回退浏览器/打字。

## 15. 监督 Agent + 自适应闭环（2026-11-13）

### 15.1 课前人机验证
- 每次点「开始上课」先出现一个**仿浏览器反爬的验证卡片**（右下角白卡：Verify you are human + 复选框 + "Protected by browser check"），不是软件内弹窗
- 勾选后 0.9 秒"正在验证…"再进入课堂；验证事件写入监督日志
- 外观可替换成真正 Turnstile/reCAPTCHA（需要站点 key）

### 15.2 反作弊（不限制第三方输入法）
- 中文/日文输入法**不拦截**（composition 事件忽略，正常输入不记可疑）
- **长粘贴拦截**：粘贴 >20 字符直接阻止并提示"请自己口述或自己打字"
- **整段插入检测**：200ms 内文本跳变 >20 字符 → 记录 `bulk-insert`
- **秒答检测**：题干出现 <1.2 秒且答对 → 记录 `fast-correct`
- 可疑标记会传给老师：老师改问"用你自己的话解释一遍"；监督事件存本地 `ops917-supervisor:v1`（最多 300 条）

### 15.3 自适应（敲打老师）
- 每课结束与**上一节同课**比较正确率：
  - 下降 >10% → `lower`：下节课老师收到"降难度、放慢、换说法"指令
  - 上升 >10% → `raise`：下节课老师"增加挑战"
- 指令存档：`ops917-adaptation:v1`；敲打反馈存档：`ops917-supervisor-feedback:v1`
- 课堂结束提示"监督：退步→已要求降难度"；练习量同时自动调整（<50% 降、≥90% 升）

### 15.4 本地存档与未来上传
- 所有监督/敲打/反作弊记录都在浏览器本地，可点「导出监督记录」下载 JSON（含 supervisor、adaptation、feedback、mastery）
- 未来接入服务器后可直接上传该 JSON 训练老师/监督 Agent；当前不自动上传

### 15.5 边界
- 网页只能监测**页面内行为**（粘贴、输入节奏、答题速度）；无法监测电脑上其他 AI 软件进程——这需要桌面端 Agent（后续）。

### 15.6 课程结束规则 + 监督 Agent API（2026-11-13）

**学生不能自己结束课程**
- 页面**没有"结束课程"按钮**（仅保留隐藏元素，点了只会提示"由老师/监督 Agent 决定"）
- 课程结束条件（两者同时满足）：**全部任务完成** + **达到最短学习时长**（默认 15 分钟，`localStorage.ops917-min-minutes` 可配）
- 任务做完但时间没到 → 监督 Agent 自动追加 2 道复习题（薄弱词听写/造句），直到满足时长
- 满足后自动结束，老师给总结，写入完成记录

**监督 Agent（DeepSeek 实时监管）**
- 接口：`POST /api/school-supervise`（`vite-plugins/school-supervise.ts`）
- 密钥：沿用 `.env` 的 `PLAN_API_KEY`（用户提供的 DeepSeek key），服务端调用
- 输入：完成题数/总题数、已用时/最短时长、正确率、可疑标记、课程名、学生档案
- 输出：`{decision:'continue|end|lower|raise', reason, extraPractice}`
- 安全护栏：**内容没做完或时长没到，模型即使说 end 也会被强制改成 continue**；只有规则满足才允许 end
- 决策显示在课堂顶部"监督：进行中/降难度/提高挑战"，并注入老师 prompt（降难度/换说法/要求口头解释）

**导出时机**
- 「导出监督记录」按钮默认**禁用 + 灰色**（`#e5e7eb`，不可点）
- **只有本节课完成后才启用**：全部任务完成 + 达到最短时长，由监督 Agent 确认结束
- 每次开始新课时按钮自动重置为灰色禁用；完成记录必须 `idx>=total` 才有效，部分进度不能解锁
- 完成状态持久化在 `ops917-lesson-completed:v1`（含 idx/total），刷新后仍可导出
- 即使绕过按钮直接调用导出函数，也会检查完成状态并拦截
- 导出 JSON 含：supervisor 事件、adaptation 敲打指令、feedback 反馈存档、mastery 学习进度

## 16. 掌握度跳过与数据留存（2026-11-13）

**目标**：学过的、已经会的内容不再重复；不会的继续练；整节掌握直接跳到未学部分。

### 16.1 判定规则
| 层级 | 条件 | 行为 |
|---|---|---|
| 单题掌握 | 连续答对 ≥2 次，或做过 ≥3 次且正确率 ≥80% | 下次开课自动跳过该题 |
| 单题未掌握 | 答错/听不懂 | 立即重置连对次数，继续练 |
| 整节掌握 | 该节完成 ≥2 次且每次正确率 ≥85% | 开始上课时自动跳到下一节 |
| 全部题目掌握 | 过滤后无题可练 | 自动跳到下一节（Lesson+1；最后一课回主页） |

- 跳过时提示"已跳过 N 道已掌握的题"（不是监督文字）
- 薄弱词/错题仍走"复习薄弱词"入口，不会被跳过
- 数据全部存本地，刷新/重启不丢

### 16.2 本地数据键（留存）
| Key | 内容 |
|---|---|
| `ops917-task-mastery:v1` | 每题 seen/correct/wrong/streak |
| `ops917-lesson-history:v1` | 每节完成记录（pct/时间） |
| `ops917-session:v1` | 未完成课堂的对话与进度（可恢复） |
| `ops917-mastery:v1` | 每课表现与薄弱词 |
| `ops917-supervisor:v1` | 监督事件（隐藏，不显示在前端） |
| `ops917-adaptation:v1` / `ops917-supervisor-feedback:v1` | 敲打指令与反馈存档 |
| `ops917-lesson-completed:v1` | 整节完成状态（导出解锁依据） |

## 17. 按教学计划推进：授课 → 小测 → 订正 → 下一课（2026-11-13）

**计划来源**：`docs/OPS_David学习方案_ABC落地_v1.md`（12 周 Unit 进度）+ `site917/public/data/od1-unit1-plan.json`（Unit 1 四课教案）。

### 17.1 每节课固定流程
1. **授课**：按教案任务（说/读/语法/听/拼写/写）逐题互动
2. **阶段小测**：内容结束后自动出 **3 题混合小测**（语法/拼写/口语/阅读优先）
3. **判定**：
   - 小测 ≥80% → 通过 → 3.5 秒后**自动进入下一课**
   - <80% → 老师**逐条讲解错题 + 给正确例子**（`mode:'explain'`）
   - 进入**订正**：错题重新做一遍；订正 ≥80% 通过并进入下一课
   - 订正仍不过 → 记录薄弱点，留在本课复习（不硬推进度）
4. **进度链**：Lesson 1→2→3→4 → 下一单元 Lesson 1（Unit 1–18）；已掌握内容会被跳过

### 17.2 严格按计划的保证
- 每课都从小测开始"过关"，不过关不进入下一课
- 掌握度高（连对/多次正确）的题直接跳过，不重复讲
- 整节完成 ≥2 次且 ≥85% → 一开始就跳下一节
- Unit 2 起若暂无手写教案，自动按该单元词汇/听说词生成 4 课练习（后续再替换成正式教案）

### 17.3 测试
- `test-quiz.mjs`：小测 3 题、全对通过并自动跳课、全错进入讲解+订正、订正通过后跳课
- `test-plan-progress.mjs`：Unit1 Lesson4 通过 → Unit2 Lesson1；Unit2 自动生成练习并可上课
