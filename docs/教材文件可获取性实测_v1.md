# 中小学教材文件（PDF 等实物文件）可合法获取性 · 实测报告 v1

> 产出日期：2026-10-01　|　实测方式：官方平台真实请求（HTTP 直连 + 元数据解析）　|　测试规模：2 册，共 6 张页面图
> 用途：一人学校 OPS 项目「按 科目 × 版本 × 年级 收集教材实物文件」的前置可行性核查
> 合规声明：全篇仅涉及**官方平台**，未使用任何盗版站、网盘合集、破解工具；PDF 原件因权限限制未取得，样本仅内部校准用。

---

## 0. 一句话结论（先看这个）

- **能免登录直接拿到"文件本体"的只有一种形态**：国家中小学智慧教育平台的**逐页 JPG 图片**（实测可取，单页 0.2–1.1 MB，整册 ≈ 47–87 MB）。
- **想要"整册 PDF 原件"，靠公开渠道免登录拿不到**——平台 PDF 被放进了需登录的私有域，实测未登录返回 **403 / 401**。
- **能合法拿到"整册 PDF（可下载/可导出）"的正规渠道都存在，但都要身份/授权**：人教数字教材（激活码）、粤教翔云（广东师生账号）、河南数字教材（河南账号）。
- **2020 年教育部公布的那批"教材电子版链接"基本已死**：实测多为 404 或域名消失。
- **面向第三方的"商用授权申请"公开入口没找到**，标 〖待核实〗。

## 1. 国家中小学智慧教育平台（basic.smartedu.cn）

**平台性质**：教育部主办的官方权威平台，教材栏目收录义务教育+高中多版本电子教材。

| 核查项 | 实测结论 | 依据 |
|---|---|---|
| 是否需要登录 | **查看需要注册登录**；但技术层面"逐页图片"可免登录直接取 | 沈阳市教育局官方推介明确"通过官网注册账号、访问平台"；实测图片直链无 Cookie 返回 200 |
| 是否有"下载"按钮 | **无**。官方口径为"暂不提供直接下载服务，仅供观看" | 成都商报报道（2024）："平台官方暂不提供直接下载服务，仅供观看，如果想给孩子打印，可以少量截图打印" |
| 下载下来是什么格式 | 平台上每册教材同时挂两种资源：①**逐页图片文件夹**（`transcode/image/{n}.jpg`，JPG）；②**PDF 原件**（`assets_document/{id}.pkg/pdf.pdf`）。**均未加密**，但 PDF 受权限保护 | 实测解析平台元数据（见附录 A） |
| 逐页图片能否取到 | ✅ **能**，免登录，实测 202 页全部 200（第 203 页起 403 表示超出页数） | 实测 |
| PDF 原件能否取到 | ❌ **不能**。公共域 `r1/r2/r3-ndr` 返回 **403**；私有域 `…-ndr-private` 返回 **401** | 实测 |
| 是否可打印/可导出 | 元数据中 `ti_printable = false`（平台标记为**不可打印**）；无官方导出功能 | 实测元数据字段 |

**关键补充**：2024 年前后网上流传"把 PDF 链接里的 `-private` 删掉即可下载"的老办法，**实测已失效**——删掉 `-private` 后返回 403。平台已把这条路堵上。

> 来源：
> - 平台教材入口 https://basic.smartedu.cn/tchMaterial
> - 沈阳市教育局《国家中小学智慧教育平台暑期应用推介》(2026-08-13) https://jyj.shenyang.gov.cn/jyyw/202608/t20260813_5071854.html
> - 成都商报报道（网易转载，2024-07-22）http://m.163.com/dy/article/J7NJV1EA0512GMQ3.html

## 2. 人教社电子教材站（jc.pep.com.cn / book.pep.com.cn）

| 核查项 | 实测结论 |
|---|---|
| jc.pep.com.cn | 页面可访问（200），是"电子教材"目录页，点封面**跳转到 book.pep.com.cn 在线阅读**，**页面本身不提供下载** |
| book.pep.com.cn | 在线阅读器（原版原式翻页阅读），**无下载入口**；对非浏览器请求返回 403（反爬），浏览器内可正常看 |
| 是否需登录/权限 | 在线阅读不需人教账号；但**只能看，不能下载** |

**结论**：人教社官网路线 = **纯在线阅读，拿不到文件**。

> 来源：https://jc.pep.com.cn/ ；https://book.pep.com.cn/

## 3. 人教数字教材（mypep.cn）

这是**唯一一条"官方提供整册 PDF 下载"的人教版正规路线**。

| 核查项 | 实测结论 |
|---|---|
| 是否收费 | **收费/授权制**。需**激活码**（或学校统一开通的账号）→ "未激活的提供激活码可进行激活，**可对已激活的进行下载**" |
| 是否提供可下载文件 | ✅ **提供**。支持"整本下载 / 分章节下载"，可选"只下载教材本体（不含内嵌资源）"或"全量下载"；支持"**导出教材包**（包括 **PDF** 和内嵌资源）"，但**导出的教材包与账户绑定** |
| 价格区间 | 官方**未公开零售价**；可查到的权威数字是**政府集中采购价**：河南 2026 春季电教教材目录中"数字教材（网络激活）"小学 **8 元/套**、初中 **12 元/套**（政府采购后免费配发给师生，非个人售价）。配套音像类（人教易视听 App）点读资源 ¥15–28 / 复读资源 ¥15–22 |
| 门槛 | 需激活码（随纸质教材/学校配发，或向人教团体业务购买） |

> 来源：
> - mypep 操作手册《数字教材平台客户端操作手册 v1.5.0》https://rjszgsres.mypep.cn/czpt/rjsz/ （含"下载/导出教材包"说明）
> - 人教数字教材产品页 https://www.pep.com.cn/products/sz/jjfa/rjszjc/
> - 河南省教育厅《2026年春季电教教材推荐目录》（含"网络激活 8元/12元"定价）
> - 人教学校团体业务电话：010-58759205（出版物购买页 https://www.pep.com.cn/lxwm/khfw/201710/t20171016_1920219.shtml）

## 7. 正版授权渠道（出版社数字教材授权 / 数字资源商用授权）

| 渠道 | 是否开放申请 | 流程/门槛 |
|---|---|---|
| 人教数字教材授权 | 半开放（激活码/学校采购） | 随纸质教材配发激活码，或走人教**学校/团体业务**（010-58759205）批量采购 |

| 面向第三方的**数字资源商用授权** | 〖待核实〗 | **未检索到公开的申请入口/流程**；通常需逐家联系出版社版权部签订《数字资源授权协议》，无公开定价 |
| 联系方式旁证 | — | 人教出版**物购买/团体业务**：010-58759205 / 58759310 / 58759341；客服 010-58759302 |

**结论**：除"激活码/学校采购"外，**面向外部机构的商用授权没有公开自助入口**，须一事一议联系出版社。标 〖待核实〗。

## 9. 给"一人学校 OPS"下一步的建议（可执行）

**路径 A：先把"逐页 JPG"当图片册用（当前唯一免登录可规模化获取的形态）**
1. 用平台教材清单接口，按 `科目×版本×年级` 拿到 `contentId`（清单含 3579 条，字段含 `tag_list`：学科/版本/册次/年级，可按标签精确筛"人教版/数学/一年级上册"）。
2. 从元数据取 `transcode/image` 目录地址，逐页取 JPG，按「科目/版本/年级」建目录，命名 `page_001.jpg`…。
3. 打包 zip 得到"图片册资料包"。
4. **合规**：仅限校内教学自用；不得再分发/商用；控制频率，勿批量爬取。

**路径 B：要"真·PDF"，走授权**
- 人教版：申请 mypep 激活码 / 走人教团体业务批量采购。
- 若面向广东/河南：对接省级平台（需本省师生身份）。

**路径 C：需要正式商用/对外发布**
- 必须联系各出版社版权部，逐家签授权协议（无公开入口，标〖待核实〗）。
