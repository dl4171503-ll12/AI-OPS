# 入学测评 40 项改造与验收

日期：2026-10-05。入口：http://127.0.0.1:919/assessment
依据：用户要求逐题、不可跳过、总计40项，以及 OPS_入学测评改造文档_v1.md。

## 实际结构与文档差异

当前工程是 React + Vite，原测评状态由 Zustand / localStorage 按账号隔离保存；不存在文档假设的 apps/api 题库数据库，也没有 echarts。本次沿用现有状态结构，新增 SVG 雷达图、Canvas 白板和 Vite 本机保存接口，未引入外部服务。

文档同时要求“生辰参与初始方向”和“文化不参与推荐”，存在冲突。本次文化开启时先录入或解锁、展示四柱/五行/结构/全部五行活动参考，再开始任务。文化关闭时全部隐藏，直接进入能力题。初始计划为中性的任务顺序与检查节奏，实际学科建议只使用答题证据。生辰仍本机计算、独立 AES-GCM 加密保存，不进入本机测评快照接口或外部 AI。

## 已实现

- 40项：24项能力情境在前，16项四科学科任务在后。共37项有标准答案、3项偏好与自述不判分。1—12年级题目数量、ID唯一性均验证。
- 无进度跳题按钮、上一题或跳过按钮。答案和至少4字依据齐全才可提交；提交后不可回改。入口总从第一道未完成题恢复。
- 老版本不会当作新版已完成。开始新版时备份旧记录到 ops-admission-legacy:<studentId>。
- 八维：语言、逻辑数学、空间、身体动觉、音乐、人际、内省、自然观察。有标准答案的题等权计算；缺证据显示待评估。实际协调、听辨和互动不由文字题冒充实测。
- 每题进入/首次作答/提交时间、经过用时。参考值为产品规则（90/120/180秒），不是年龄常模。刷新和切后台不重置；离开页面时间计入，慢不直接判能力弱。
- 每题收集输入、选择、把握、白板和提交步骤。连续文本输入800ms内合并最新记录，草稿每次变动立即在本机保存。
- 每题白板：黑红蓝绿、粗细、橡皮、撤销、重做、清空、PNG导出。笔画随答案保存，报告按最终笔画序列重绘/回放，操作历史另列时间线。
- 每次提交形成计划版本及前后建议、进度、正确率、用时快照。低正确率补基础、充分且快速的正确证据增加迁移挑战、慢题询问是否有暂停或其他困难、每10项阶段检查。完成后四科学习计划实际写入校园。
- 学情浏览器自动保存，提交后同步到本机 .ops-data/assessment/ 独立快照，服务记录独立 savedAt。断网不阻止本地答题，恢复网络自动补存。服务仅接受本机同源、带自定义头的POST，检查路径标识与8MB上限，静态访问排除数据目录。

## 边界

这是基于本次小样本的学习证据，不是标准化心理或智力测验。推理文本和白板不自动判分，需要人工复核；未接入手写识别。文化解释沿用已有四段本地讲解，不调用外部AI。暂不实现奇门/星象。白板回放逐笔展示最终保留笔画，不重演撤销前被删除的轨迹；操作时间线保留撤销/清空动作。

本机服务快照用于恢复与审计，不是远程云数据库。浏览器与服务运行在同一机器，断网仍保留客户端时间，网络恢复时另记接收时间。机器时钟改变不能据此获得可信防作弊计时。存储满时页面明确报错并阻止当前题提交，不静默丢弃草稿。
