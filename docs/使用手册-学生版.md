# AI一人学校 · 使用手册（学生版）

## 入学
1. 打开网站，输入名字、选头像、选年级
2. 点击「创建我的学校」，观看建造动画后进入校园

## 校园主界面
- 六栋教学楼：数学 / 语文 / 英语可用；科学 / 艺术 / 体育为预览位
- 校长办公楼、心理咨询室、娱乐探索楼、探索广场、校际社交广场
- 左上角看自己的年级段、学习天数、徽章

## 学科楼（以数学为例）
1. 首次进入做学情测评
2. 查看学情档案，生成「今日任务」
3. 练习题：AI 出题 → 提交 → 即时讲解
4. 错题进入错题本，可「重练同类」
5. 学习报告查看正确率与弱项
6. 完成今日任务后解锁娱乐时间

## 校长与心理老师
- 校长：问本周优先级、聊目标
- 心理老师：说烦恼；系统只给家长情绪摘要

## 娱乐与探索
- 娱乐楼：体育 / 美术 / 音乐 / 编程兴趣室
- 探索广场：十万个为什么 + 彩蛋

## 社交
- 用邀请码加好友，温和聊天、互赠贴纸
- 不要发手机号、微信等个人信息（会被拦截）

## 晋升
学习达到条件后可触发晋升仪式，校园风格会升级。
